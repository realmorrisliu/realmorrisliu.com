这些计数是源文件事实，不能自动认证城市代表性、测量时效、信息独立性或指标有效性。字段后缀年份也不一定是单年观测期，例如温度按十年窗口描述；来源单位、时期及代理关系详见指标语义规则。

医院字段还存在交叉缺失：199 个中心的医院计数为空但医院邻近人口占比非空，另有 2 个反向情况。因此尤其不能将空医院计数自动填成零。两字段标记年份不同，本次只记录不一致，不推断原因或自行修补。

## NaturalSystems 重复记录不能直接删除

11 个重复 ID 的重复行在非几何属性上都只在 `NS_TPA_PER_2025` 值有差异；不是完全相同的重复行。例如 Aachen 两条值分别是 18.52957757 和 0.043504036。取第一条、求和或取最大值都需要额外证据，不能当成技术去重自动执行。

该结论不证明几何列完全相同：本次字段扫描不含几何，空间核查使用主表几何。完整冲突 ID 和取值已写入 JSON，后续关联必须显式拒绝未解决的冲突字段。

## 复算

```sh
pnpm exec python3 -B scripts/test_cci_ucdb_field_audit.py
pnpm exec python3 -B scripts/cci_ucdb_field_audit.py \
  --ucdb /private/tmp/cci-global/GHS_UCDB_GLOBE_R2024A.gpkg
```

脚本只使用 Python 标准库。先核对原文件 SHA-256、实际表结构、行数与唯一 ID；计算前不替换、插值或去重。测试覆盖空值／零／文本／非有限数区别，以及有冲突和无冲突的重复行。输出是数据盘点，未向旧功能区转移指标，未生成 CCI 分数。
