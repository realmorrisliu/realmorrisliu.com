# LON 干预纳入规则 v0 与边界判例

日期：2026-10-10。本规则落实既有 LON 的长寿专项转化、临床成熟度、监管采用、居民可获得性四个子支柱；不改权重，不以试验数代替维度分。它是 CCI 的研究操作规则，不是医学共识量表，也不是已完成独立复核的分类器。

[NIA 的 geroscience 说明](https://www.nia.nih.gov/gsig)将衰老机制与多种慢病及功能下降相联系；[NIA 第四届峰会说明](https://www.nia.nih.gov/research/dab/workshops/fourth-summit-geroscience-next-generation)强调从衰老生物学发现到候选干预及临床试验的转化。以下分类借此澄清研究对象，不把机构定义直接当作 CCI 得分标准。CCI 既有医学情景也包括再生平台，因此不将 LON 缩成只研究某一种药物。

## 统一纳入边界

阅读方案中的目的、干预、研究人群和实际终点后分类，而不是仅检索标题关键词：

- `include_intervention`：明确针对衰老生物过程、年龄相关功能衰退／衰弱的转化干预。药物、生物制品、再生技术和有相应机制假设的非药物干预均可纳入；单病种试验如果用于检验上述机制，不因只招募一种疾病人群而自动排除。
- `include_linked_followup`：为已纳入干预提供人体长期结果的关联随访。与母试验相连，保留观察性设计及选择／失访限制，不能重复算成独立随机证据。
- `outside_current_scope`：现有方案只支持局部美容外观、常规单病诊疗或一般服务改进，且未建立上述转化目标。它仍可能是 MED、TEC 或背景线索；这不是对所在城市的扣分，也不是干预无效的判断。
- `needs_scope_review`：目的、机制或功能目标不足以区分上述情况。保留待核验，不自动排除，也不默认为纳入。

年长受试者、Aging 标签、“抗衰”营销名称、干细胞／外泌体等技术名词，均不是充分纳入依据；也不能反过来仅凭一种干预类别排除。一般运动和营养研究需检查具体方案，避免将全部健康促进研究归给 LON，或将真正的机制转化研究遗漏。

纳入只回答研究与概念是否相关，**不回答是否有效、成熟、获批或居民可得**。终点须记录具体测量方法与观察期，区分安全性、机制／替代指标、功能结果、临床事件和生存；名为 Healthspan 的终点仍需查看定义。分期、随机设计、完成状态和结果方向分别记录，不能合成一条自动等级链。

## 已完成的八项边界审查

依据冻结的 [4,041 项发现集](cci-lon-registry-inventory.md)原始记录，逐项阅读设计、摘要／详述、干预与主要终点。除前一轮 CALERIE／PEARL 结果核验外，本轮不声称已检索各项结果论文。完整理由、原始页哈希和 JSON 指针见[审查记录](data/cci-lon-scope-review.json)。

| 注册 ID     | 判定         | 决定性证据或保留问题                                                                  |
| ----------- | ------------ | ------------------------------------------------------------------------------------- |
| NCT00427193 | 纳入干预链   | CALERIE 热量限制与衰老相关适应；不将代谢指标当作延寿                                  |
| NCT04488601 | 纳入干预链   | PEARL 正常衰老人群雷帕霉素研究；相关性与结果强度分开                                  |
| NCT06145087 | 纳入干预链   | STAMINA 明确针对衰老机制；主要终点是血流介导舒张                                      |
| NCT02065245 | 纳入干预链   | 老年衰弱的细胞干预；主要终点是安全事件，非功能疗效                                    |
| NCT05651620 | 纳入关联随访 | CALERIE Legacy 为母试验长期随访；Healthspan 在该记录中使用代谢综合征 z 分数，不是年数 |
| NCT05813379 | 当前范围外   | 已列终点针对面部皱纹／胶原等局部皮肤外观；不能由外泌体名称推成系统性长寿证据          |
| NCT04064528 | 待复核       | 年龄组间氨基酸到肌腱周围的浓度差异，需要补足功能转化关系                              |
| NCT01775111 | 待复核       | 训练、蛋白补充与肌肉／免疫测量，需要厘清一般康复与长寿专项转化的边界                  |

这些判例为检验规则而有目的地选择，**不是随机样本**；4／1／1／2 的分布不能外推到全库，也不是城市覆盖率。单次审查未验证评估者间一致性。全库仍有 4,033 项未经此次范围审查，八项均没有完成监管、居民可及和 FUA 归属链条，因此原发现表的 `not_adjudicated` 作为采集时状态保留，审查结果单列，不改全候选 LON 覆盖状态。

## 下一步进入完整证据链的条件

优先复核上述待定边界，并按同一规则审查其他记录；任何自动文本筛选只用于安排审查顺序，不能证明未命中者不相关。对纳入项逐一保留具体结果、主要分析人群、风险与反证、许可适应证、研究执行地点及居民资格／费用；关联随访回到母干预，避免重复证据。其他注册平台及 Aging 查询未召回研究仍需另行发现与去重。

城市判断最终依赖当地的转化和实际获得条件，不能把全球已知干预的效用独占分配给其发明地。此规则目前提供可检查的纳入边界，尚不支持自动生成 LON 或全球 Top 32 分数。
