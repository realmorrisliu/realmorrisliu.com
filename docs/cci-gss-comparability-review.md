## 可操作共同边界

[共同rubric](cci-global-scoring-rubric.md)的60原文是“现实暴力影响较低且具缓解能力，但区域或战略威胁仍重要”；39段同时要求报道覆盖、邻区与战略情景检视，长期无记录不能单独支持低影响。[指标契约](cci-global-indicator-contract.md)的regional_conflict与strategic_exposure尚无完成的统一UCDB代理，首都／港口／机场存在不是已测攻击概率。这两条不等于要求三种危险都已经在本地实现。

1. **限定现实影响或观察覆盖。** 对相关组织暴力／区域与战略危险，记录观察窗、分类、地理范围、受害与通道影响、来源选择及报告覆盖。当前主管分类观察、地方个案／实际拦截与有范围运行记录可共同支持窄推定；不必全年度全人口普测。不用普通罪案总量、逮捕数或无匹配事件代替低影响。
2. **检视相关情景并映射地方。** 国家／地区风险评估可适用，但须说明本地人群、实际节点、共享供水／运输依赖或具体目标怎样关联；包含低直接暴露但重要尾部风险。零已知成功攻击也能是有限观察，不能变成“绝无危险”。只列国家等级、大学／首都名、设施名称，不构成映射。
3. **让运行中的能力对应相关威胁。** 现场处置、实际拦截／调查、目标社区保护、SOC及设施实体保护、真实互援或明确情景的已实施演练可计入。演练证明有限准备，不能写战时结果；已运行保护不必等成功袭击才有意义。普通抢险／运输恢复只能证明其对应部分，不能跨语义覆盖所有GSS。
4. **公开必须接受的推定与反证。** 通常居民触达、地界、有限来源的代表性、截止延续与剩余影响都可以条件判断，但须说明凭什么推定、何时拒绝。不能用“多数时间仍运行”排除针对社区的重大伤害；40不要求多数人口已经受害。新国家预测或一般服务再多也不能替代尚缺连接。
5. **档位与未知分开。** 20／40需要现实严重／重要剩余约束的证据；60接受低现实影响＋真实适配能力但重要尾部；80还要城市与区域共同检视的更强低影响／关键应对链。必要推定拒绝即null，不将未知硬记40、60或零，也不把60三个子项等权平均。

`partial/context/unresolved`描述证据状态，不是分数。context可以作为明确适配的背景参与条件主判断，但不能将context改名partial掩盖未核连接；战略子项尚未完整测量并不机械禁止60。同样，组织暴力一项真实也不能独自覆盖整维。

## 哪些旧60需要更明确的弱连接，而非默认保全完整中心

Beijing／Shanghai／Guangzhou有具体组织伤害、程序处置及地方防空／设施保护动作，可在相关情景和通常影响推定下保留60；但不能把破案率、少量选定受害、演练人数或共同台海公告变成低城市发生率／战时结果。Surabaya有实际地方受害援助及军港Force Protection实训，泛海港流量／非恐袭气爆救援不可代替战略部分；若只保留后一组，60需撤回。以上本轮文本检视，不宣称逐份主管原件裁决。

Nanjing／Wuhan／Xi'an的当前通常影响推定更弱，**需要优先重新确认，不是确认旧60不变**：Nanjing有曾打击后再活动、审理非终判；Wuhan主要组织伤害较旧；Xi'an旧村案点未核且当前执行总量不等受害／恢复。这些条件若父任务不能接受，应撤回null；若确认重要未缓解的持续侵害可40。最小工作是既有材料的时点／地点／残余与具体城市保护情景适配解释，或一条有判别力近期观察，不继续堆总量、不因没发生战争才撤回，也不由本轮时间不足撤回。

相较新null，旧60较合理的区别应是**已有更明确情景映射与实施保护／限定现实影响**，不是已完整出总分所以放宽。若两城都只有历史结案＋国家等级＋普通服务，就应使用同一未知判断；若新null已经有相应风险检视与现役能力，也允许同层条件60，无需先等战略攻击。本轮没有对其余旧60的所有上游原件作终局保证。
