## 为何允许探索排序，同时不能预测CCI

短模型医疗旅行、较低参考岩石地震危险、较少城市中心热压力和较快已测试连接，分别可能减少必要治疗到达、部分自然暴露和日常数字使用的障碍。在这些方向上同时有利的候选值得先核地方实际结果。这是明确但未经验证的推定：代理可能与2026能力延续相关，存在未知误差；没有从代理到40／60／80的映射。

这些变量只涉及MED／PCS／TEC的部分内容，GSS／ISR／RES／LON／OPT和前三维其余子项仍未闭。国家背景也不补城市执行。因此本轮计算的是**工作优先值**，而不是降低后的CCI或预测分。研究发现费用阻断、风险未缓解、服务失效、权利或退出限制时，可以推翻工作假说。论文、机场、来源数、测试次数、人口、城市知名度及地域配额均未进入优先值。

## 可复算的最简工作模型

脚本[cci_research_priority.py](../scripts/cci_research_priority.py)只读公开仓库原料，用整数`efua_id`重建完整行，不依赖旧`screen.py`或私有派生底表。医疗、地震、矩阵和候选均核9,031唯一且同一ID集合；网络保留fixed／mobile，UCDB原属性核11,422唯一ID，正面积交叉表核9,743关联。参数气候文件可为官方GPKG或验SHA的属性CSV；缺失不补零，非有限值拒绝，工作输出中`cci_score`全部为空、保留状态不变。

四族定义如下；所有指数尺度、速度饱和点及权重均属公开的未经验证工作假设，未按想要的城市调参。

| 族／公式                                                                       | 原观察范围                                                                                                  | 假说与限制                                                                                                                                                                                                                        |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `M=(exp(-motor/10)+exp(-walk/60))/2`                                           | [2019医疗旅行模型×WUP2025投影人口](cci-healthcare-population.md)，分钟条件均值                              | 短旅行可能有利；只含有旅行值的人口，不是2026实际等待、医疗质量、资格、费用或全体患者分母。                                                                                                                                        |
| `Q=exp(-PGA/0.1)`                                                              | [GEM2023.1参考岩石PGA](cci-seismic-population.md)，g，50年10%超越概率                                       | 较低模型暴露；不含场地放大、建筑、实际损害或防護。源零可保留，绝不等于零灾害风险。                                                                                                                                                |
| `H=exp(-heat/30)`，`E=(Q+H)/2`                                                 | UCDB R2024A v1.2 `CL_UTC_T32_2020`；取与FUA正面积相交的新版中心原值最大值，天／年                           | 原字典为一个十年内每日最高UTCI>32°C日数的年平均，来源ERA5／C3S；2020模块不当2026实测，也不猜十年精确起止。最大中心值不是人口加权全FUA热均值；热／震合为一个暴露族，避免冒充两个完整维度。洪水、冷、海平面、强天气、野火未被覆盖。 |
| `N=(min(1,log1p(fixedMbps)/log1p(300))+min(1,log1p(mobileMbps)/log1p(150)))/2` | [Ookla Q3 2026自选测试](data/cci-ookla-efua-sampled-measurements.json)，瓦片中心归属、测试加权下载kbps÷1000 | 固定300／移动150Mbps以上饱和，避免最快测速无穷主导；普通使用适用性仍为假设。不能证明无连接者、普及、价格、可靠性、知识、产业或转化。测试次数仅保留诊断，不排序。                                                                  |
| `B=mean(WGI GEscore,RLscore)/100`                                              | [WGI2026更新中的2025国家背景](cci-wgi-country-context.md)，两个相关国家指标                                 | 仅可撤回的制度先验；不是本地ISR观测，两项不算独立城市结果。去国家情景权重为零，缺B不影响该情景可算性。                                                                                                                            |

严格Pareto另只用`M/N/E`：至少一个严格更优且三项均不差才支配，同值不互相淘汰。本地三族可读的未审**6,857**项产生**21**项前沿；无需B。不用前沿资格排除其他候选，Tampere虽不在本地前沿仍保留其跨情景工作位置。主任务另做全量暴力核对，确认所有非前沿确有前沿严格支配；这只核算法，不确认城市能力。

热源PDF字典关键原表**p166已目视**，文本、PNG与原CSV核对。UCDB洪水字段的EX010／EX100名字与十年／百年描述存在未消解对应矛盾，本轮不选该字段；HAZARD_RISK中混含riot／protest的事件不自动成为组织暴力，医疗设施数不当质量。没有把未选变量变成城市缺陷或透明度扣分。

## 仍不能由模型判断的层

国家背景不替本地执行，医疗旅行不替必要护理质量／资格／支付，测速不替普及／可靠性，热震不替所有灾害和实际保护。GSS／ISR／RES／LON／OPT没有城市实际代理，权重和饱和尺度也未经验证；低代理障碍只能提高研究优先级，不能补60。不同年代、中心边界、自选样本和缺测关联可能系统性改变短名单。

后续较有辨别力的一手入口包括[JRC／EC2023城市生活质量原调查](https://joint-research-centre.ec.europa.eu/scientific-activities/survey-methods-and-analysis-centre/quality-life_en)的必要服务／安全感／地方信任和[OECD Local Data Portal](https://www.oecd.org/en/data/tools/oecd-local-data-portal.html)的城市／FUA实际服务与环境。须先核地界、抽样、年代与普通居民适配；未下载的原报告仅记网页工具入口，不列原件SHA，不照抄外部综合榜，不因非覆盖国家资料少排后。本轮两轮检索到此停止。
