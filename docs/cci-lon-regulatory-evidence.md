# LON 监管证据与已验证的检索遗漏

核验日期：2026-10-10。本轮比较两个欧盟产品的适应证，并从监管研究反查注册 ID。它们是证据链的判例，不是全球药品清单，不给任何城市补分。

| ------------------- | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| Rapamune／sirolimus | EMA 产品信息 2026-06-04 更新；第 4.1 节列成人肾移植排斥预防及特定散发性淋巴管肌瘤病                    | 这份许可不包含一般抗衰老用途。不能把它作为 PEARL 所研究用途已获批的证据，也不能把 PEARL 配制制剂直接视为相同获批产品 |
| Zokinvy／lonafarnib | EMA 页面 2026-10-07 更新；适用于满 12 个月且基因确诊的特定早衰综合征／核纤层蛋白病，具体突变条件见原文 | 存在针对特定早衰疾病的获批治疗及生存证据；不能外推为一般居民抗衰老收益，也不能推定所有居民满足资格                   |

来源：[Rapamune EPAR](https://www.ema.europa.eu/en/medicines/human/EPAR/rapamune)、[产品说明第 4.1 节](https://www.ema.europa.eu/en/documents/product-information/rapamune-epar-product-information_en.pdf)、[Zokinvy EPAR](https://www.ema.europa.eu/en/medicines/human/EPAR/zokinvy)。Zokinvy 的 PDF 本轮读取遇到 HTTP 429，未取得其完整最新产品说明；上述适应证依据官方 EPAR 页面，未冒充已读 PDF。

FDA 审评作者的 [lonafarnib 批准总结](https://pubmed.ncbi.nlm.nih.gov/36507973/)说明，关键证据比较开放标签试验患者与未治疗队列，涉及生存终点；不是健康老年人随机试验。此类证据既不能因非随机设计而机械记零，也不能脱离疾病、人群及外部对照的限制。这里不合并不同监管文件中的生存增益数值。

[FDA 对超说明书使用的说明](https://www.fda.gov/patients/learn-about-expanded-access-and-other-treatment-options/understanding-unapproved-use-approved-drugs-label)将获批产品与未获批用途区分开。处方可能性不能替代相应用途的监管结论；这一美国说明也不能被当成所有辖区相同的法律规则。本轮未核验欧盟各国处方、报销、实际库存及城市接诊渠道，居民可及性仍待定。

## 单一 Aging 查询已有明确漏检反例

上述 FDA 批准总结列出 NCT00425607 与 NCT00916747。已单独下载两项 API 记录，核对 ID、条件字段和最后更新日期；在冻结的 4,041 个 NCT ID 中，两项均不存在：

| 注册 ID                                                     | 注册条件                              | 最后更新   | 冻结 Aging 查询 |
| ----------------------------------------------------------- | ------------------------------------- | ---------- | --------------- |
| [NCT00425607](https://clinicaltrials.gov/study/NCT00425607) | Progeria；Hutchinson-Gilford Syndrome | 2019-06-25 | 未命中          |
| [NCT00916747](https://clinicaltrials.gov/study/NCT00916747) | Progeria                              | 2023-02-27 | 未命中          |

这是检索遗漏的直接证据，不是对召回率的估计。原发现集确实完整取回了该查询的全部分页，但**查询完整不等于相关研究完整**。保留原快照不回填改变其查询含义；这两项通过监管来源另行发现，不能静默加入原查询计数。它们的 LON 具体相关性及城市链条仍需按相同规则审查。

[来源清单](data/cci-lon-regulatory-source.json)记录两张监管网页、一份 PDF、两项 API 响应的字节数和 SHA-256，以及用于遗漏比对的发现表哈希。原始字节位于本机研究缓存；仓库产物不包含联系人字段，也未新增城市得分。

## 下一步改变

发现路径至少需要同时保留：条件／机制查询、干预名与别名查询、监管评估引用试验，以及其他注册平台。按稳定注册 ID 和跨平台关联去重；各路径保留出处，不能以某路径未命中证明不存在。先用已知遗漏项检查扩展检索能否找回，再审查结果相关性；不能把这两项找回误称为召回率达标。

监管记录的最小比较单位是具体产品／制剂、用途、人群、辖区和日期。此层完成后仍须核验居民获得条件。全候选 LON 状态保持未形成完整评估，目标仍未达到全球 Top 32 发布条件。
