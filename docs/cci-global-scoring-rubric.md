# CCI 全球研究评分：共同判读规则草案

日期：2026-10-10。依据[现行研究模型](cci-research-model-v2.md)与[31 子支柱语义审查](cci-global-indicator-contract.md)。这是待用真实证据校准的方法草案，不是来源机构发布的评分标准，也尚未成为生产模型。没有给城市补分或改变八维权重。

## 评价对象与时间

比较冻结候选范围内、2026 年证据截止日的八维能力。早年测量保留实际观察期，不能用采集日期替换；对当前状态的推断另写理由。未来情景不能混入当前中心值。

用户于 2026-10-10 选择分别评价当地居民与跨国迁居者，暂不合成单一榜单。两种视角均沿用八维权重及完整候选范围，各自审查 Top 32，不以一份名单作为另一视角的候选池。

| 视角         | 共同评价条件                                         | 尚须查明的事实或参数                                                                               |
| ------------ | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 当地普通居民 | 本国公民、通常长期居住、当地中位收入及通常医保条件   | 统一收入统计单位与观察期；当地保障资格、等待期、个人负担；具体治疗的年龄和适应证条件不能默认满足   |
| 跨国迁居者   | 同一基准人物跨城市比较，不随目标城市更换其国籍或财富 | 国籍、已有居留权、家庭与年度可支配预算待用户指定；此后逐地核验入境到长期居留、工作、医保及税务条件 |

跨国视角必须区分“能否合法迁入”和“迁入后能获得什么”。不能假定外国人已取得目标地公民权或永居，也不能把短期入境资格当作长期迁居资格。缺少画像参数时该视角的身份依赖结论保持待定，不阻止当地居民视角及共同证据工作。

原始证据按来源保存一次，两种视角各自解释其适用性。物理危险、设施或事件底表可以共享；居民暴露、支付能力、法律资格及应对条件可能不同，不能默认整项维度得分相同。两榜不平均，也不取两者最高分作为新的综合榜；各自公布覆盖、限制与入围不稳定性。此决定不改变已有历史发布。

“全球”仍受候选边界约束。1,861 个新版 UC 与旧 eFUA 完全不相交的问题没有解决，不能只对旧库排完序就宣称覆盖当前全球。旧 32 城不作为分数标尺，不要求复现它们的相对次序。

## 八维的共同档位含义

维度继续整体判断，不新增未经论证的子支柱等权平均。下表是判读方向，不是硬阈值、自动打分规则或已完成校准的量表。同一事实的存在、强度、影响人群与缓解措施需要一起看；一项反证不自动决定整个维度。

| 维度与全部子支柱                            | 20：严重结构性脆弱                                       | 40：明显约束                                             | 60：能力较强但仍有重要短板                                 | 80：强大且有冗余                                                           |
| ------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------- |
| PCS：热湿、洪水海平面、地质、强天气野火     | 有依据的严重暴露与防护失效组合，居住或关键设施受重大威胁 | 重要危险暴露与防护缺口同时存在                           | 主要危险有适配防护，但特定人群、地点或失效情形仍明显脆弱   | 多类相关危险均有暴露与防护依据，关键措施有独立备援及有效性证据             |
| GSS：组织暴力、区域冲突、战略暴露           | 严重暴力或战争影响有直接依据，基本安全持续受威胁         | 冲突、外溢或战略风险对生活与关键通道形成明显约束         | 现实暴力影响较低且具缓解能力，但区域或战略威胁仍重要       | 城市与区域证据共同支持低现实影响，关键威胁和应对能力经过检视               |
| ISR：治理、适应能力、社会凝聚、应急恢复     | 执行与恢复能力出现有记录的严重失效                       | 服务执行、群体信任或应急交付存在显著障碍                 | 主要制度与服务可运作，部分适应、群体或恢复环节仍薄弱       | 执行、群体触达与恢复有结果证据，替代组织与资源能在压力下发挥作用           |
| RES：水、食物、能源、供应链                 | 基本资源持续不可得或中断对居民造成严重影响               | 供给、可负担性或依赖集中度形成明显约束                   | 日常供给可靠，但关键来源、库存或备用通道仍有短板           | 基本供给与可负担性有证据，替代来源和备用通道能应对共同冲击                 |
| MED：可及性、常规质量、专科能力、连续性     | 必要治疗不可及或严重服务失效有证据                       | 就医资格、费用、质量、专科或连续性有显著约束             | 广泛常规与必要专科服务可得，但等待、群体或压力运行有短板   | 可及性和治疗质量均有证据，专科转诊与压力下持续服务存在有效备援             |
| LON：转化、试验成熟度、监管采用、居民可及   | 有证据表明转化和安全采用能力受到严重结构约束             | 研究到人体结果、监管或居民获得之间有明显断点             | 存在可信人体证据及转化路径，但成熟度或普遍可得性受限       | 多条可信转化路径与审慎监管、实际居民获得条件共同支持强准备度               |
| TEC：知识产出、产业密度、数字设施、扩散     | 知识生产、产业应用或基本数字接入受到严重约束             | 有局部活动，但产出、产业连接、设施或实际采用存在明显断层 | 科研与产业有持续产出、数字设施较强，但扩散或群体接入有短板 | 多机构和产业形成持续能力，数字连接及广泛采用有证据，关键能力不依赖单一节点 |
| OPT：交通冗余、法律迁移、资产可携、网络连续 | 对指定居民，离开、转移基本资源或保持连接受到严重限制     | 物理、法律、金融或数字通道存在重要约束                   | 多类通道可用，但资格、容量、共同失效或资源转移有短板       | 指定居民有实际可用的替代交通、合法迁移、资产及通信路径，共同失效受到检视   |

PCS 的低暴露也可支持较好判断，不要求低危险城市建设不必要的防护设施。GSS 的长期无记录不能单独支持低影响；需同时检视报道覆盖、邻区与战略情景。LON 的“强准备度”不等于已证明延长人类寿命；未有广泛获批干预也不能将所有城市直接记零。OPT 的机场多、免签地多或网速快均不能单独覆盖本维。

20、40、60、80 之间每 5 分的精细差异，只有在证据能解释为什么更接近某档时才使用。0 和 100 不由样本最差／最好城市自动获得；不做候选样本内 min–max 或百分位映射。真实比较前需用多种能力组合检验档位一致性，草案本身不足以证明间距相等或总分有客观精度。

## 一份可复核判断需要回答什么

每城每维的现有 rationale 和离线证据记录应回答：

1. **支持与反证分别是什么？** 覆盖该维全部子支柱，缺项写明。保留原值、观察期、空间和来源身份。国家背景可支持共同环境判断；地方差异必须有地方或适配地区证据。
2. **为什么落在这个档位？** 将证据与表中条件对应，说明主要约束及可缓解程度。不要只写“领先”“安全”“发达”。没有证据不是低档证据。
3. **何种新证据会改变结论？** 指出实质敏感项，例如医院实际接诊资格、备用供水通道能否运行，而非笼统扩大半宽。未取得结果时保留待定，不把“未发现问题”写作无问题。
4. **是否重复使用同一事实？** 同源上游不当成独立佐证。同一设施可以说明不同能力，但不能把存在本身重复奖励到多维。临床研究活动不代替医疗疗效，科研产出不代替居民可得。

缺少关键证据但仍能支持方向时，允许写条件性研究判断；必须同时记录依据和缺口。如果信息不能区分相邻档位，应保留多个可辩护档位用于敏感性分析，不能为凑完整分数统一填 50。现有引擎的 ±8 至 ±20 是展示用研究假设，不适合强行容纳任意未知，也不能用来排除未评估候选。

## 信息缺失与信息环境的判读

用户提出，排除研究者获取渠道的限制后，信息稀少本身也可能反映问题。研究中须分开记录“被评价的能力未知”与“已核实的信息环境缺陷”：查不到治疗结果不证明治疗质量差；已核实的接诊指引缺失却可能增加居民实际就医障碍。资料丰富度不直接作为城市能力或总分指标。

将信息缺口作为负面证据前，逐项记录以下核查；任一关键条件未知时，只保留待查，不自动扣分：

1. **预期是什么**：明确应存在的统计、登记或居民服务信息、责任主体、适用人群和更新周期。法定披露义务须引用已核实的规定；没有法律义务时，说明所检验的服务需要，不把研究偏好说成违规。
2. **渠道是否适配**：记录当地语言、主管机构、线下或电话服务、国家／区域集中发布及替代入口的检查范围和日期。网站故障、搜索引擎未收录、研究者访问失败不能证明居民无法获得信息。
3. **缺口是否成立**：区分未建立测量、已测量未公开、过期、无法使用和因隐私合法限制披露。没有找到公开数据不能推断不存在内部监测；未获回复也不能单独证明隐瞒。
4. **后果与归属是什么**：说明实际影响及其证据，适配城市边界和居民视角。公共问责缺陷可支持 ISR 判断，接诊条件不清造成的障碍可支持 MED 可及性判断；同一事实不因重复引用而在多个维度重复奖励或惩罚，也不增加第九维或改变权重。

仅在登记范围、时间、完整性与记录义务均核实后，登记中无活动才可支持“该登记范围内无相应活动”；不能扩大为整个城市没有能力。信息充分也不自动证明表现好，公开负面结果不应仅因暴露问题而比未披露者受到更多惩罚。

比较城市时使用相同的查证项目、截止日和停止条件，并保留替代解释及能推翻判断的新证据。现有网络缺样本、OpenAlex 无机构落点、医疗模型缺像元均是数据覆盖状态，未经上述核查不能转为当地透明度不足。此次补充是共同判读规则，不代表已完成全球披露审计或取得城市数值扣分依据。

## 用现有证据检验规则

| 已有证据情形                           | 允许的结论                         | 目前不允许的打分推断             | 下一条有辨别力的证据                     |
| -------------------------------------- | ---------------------------------- | -------------------------------- | ---------------------------------------- |
| 某 eFUA 在 UCDP 匹配窗口没有已归属事件 | 该规则未匹配到事件                 | GSS 自动 80 或 100               | 粗定位事件、来源覆盖、邻区影响及战略暴露 |
| 某地人口加权医疗旅行时间较短           | 对有记录人口，模型中的地理通达较好 | MED 全维高分                     | 实际可接诊资格、费用、治疗结局和连续性   |
| 同国两城共享 WGI 背景                  | 国家层面相同参考信息               | ISR 两城等分，或凭知名度拉开差距 | 适配当地的执行、触达与恢复结果           |
| 网络下载、上传、延迟、设备数均为零     | 记录需要来源解释                   | 零延迟加分、零网速扣分           | 原始测试覆盖和生成方法                   |
| 城市有早期人体试验站点                 | 对应研究活动确实存在               | LON 居民可及或临床获益已成立     | 干预结果、适应证、监管与居民获得条件     |

这五项检查已用于草案逻辑复核，不是新增城市评分，也不是跨评估者一致性检验。下一步须用同一证据记录形式落实完整维度判断，并检验未评估候选是否仍能改变入围边界。规则、数据或居民口径未稳定前，不进行全球总榜发布。
