# 广州功能区：资源与医疗的实际交付和关键缺口

证据截止 **2026-10-10**，核读 **2026-10-12**。冻结 eFUA **9711／Guangzhou**，2026 年本国公民、通常长期居住、当地中位收入与通常医保。按[共同规则](cci-global-scoring-rubric.md)审阅 RES／MED 的全部 8 子支柱，不由子支柱等权平均定档。

**RES 可采用条件性 60；MED 暂未选档。** 水、电、实际食品交易及已完成燃气改善支持通常供给可用的研究判断；外部来源、城中村与末端设施、价格和共同冲击仍须保留。医疗有真实治疗、支付与质量记录，但较早队列、当前多提供者结果解释和跨广州／佛山通常居民必要治疗的连接尚未完成。未定不是零、不是医院没能力，也不由其科研或单病转化填 60。

## 边界与停止规则

[防护复核](cci-guangzhou-protection-institutions-review.md)和父任务全 9,031 几何核验确认：广州中心、佛山城区和黄埔近似参考点属于 9711；白云机场／花都为 9741，番禺／南沙为 9716，增城／东莞为 9718，从化为 9787。近似点不代表全部市域、医院院区或服务覆盖。**不能把广州行政市的水样、医保和统计全部给佛山居民，也不能把佛山全市都归 9711。** 区外电源、粮食或医疗可以服务本区，但实际连接仍需解释。

本次临床优先核原观察期、入选／排除、单位／分母及原表，再区分过程、结局与支付。不以更多接诊量代替质量解释，不独增必须取得全体居民精确账单的门槛。已取得的佛山正式待遇条款另列[窄核查](cci-guangzhou-foshan-insurance-review.md)：2026-05-01起，三级职工／居民起付1000／1200，政策范围内支付87／80%；赴广州转诊减10个百分点，非急未转诊临时外出减20个百分点。通常居民断保／逾期固定等待3个月，职工断缴和跨制度转换另有条件；直接结算失败可能先全额垫付。相同FUA不消除参保地／就医地分流，名义比例也不是整张账单报销率。当前原件的字节不证明截止前完全相同。
