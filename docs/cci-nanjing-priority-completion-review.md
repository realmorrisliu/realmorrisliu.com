## 为什么可提出60，哪些情况必须撤回

[东京 MED 案例](cci-local-2026-tokyo-case.md)允许真实急诊／专科／转诊和费用保护、急救压力与透析协调反证并读后，在常规质量未完整测量下作条件60；[武汉窄复核](cci-wuhan-medical-quality-review.md)以历史必要护理改善、实际持续透析和当前运行作当前延续推定；[杭州](cci-hangzhou-resources-medicine-review.md)使用2024单中心过程、必要专科、现行参保／透析支付，并明示代表性与净負担推定。三者均未要求完美中位账单、全区风险调整质量或每节点当期压力测试。南京也不应把“所有已整改医院必须先有当前同口径结局”额外设为入60硬门槛。

南京此前null有合理待核点。本轮取得的常规护理过程／结果，比仅有专科规模和培训增加了辨别力；实际专科、管理改善、转诊、真实付款及办理入口可以合成同层级方向。**60是对广泛常规和必要专科通常可用、仍有显著群体／费用／压力短板的研究判断，绝非已证明每种缺陷充分修复。** 需同时接受：

1. **范围／代表性**：作者匿名单院及所列核心医院实际能服务9701通常居民；没有误把外区分院或外来患者总量当本区质量率。
2. **延续／适当性**：2023—2024感染与合理用药管理延续，2025多院已交付整改和平台运行对当前必要护理具有实质意义；高风险并发症不全作失误，但真实质管缺陷也不消去。
3. **资格／负担／及时替代**：通常基本医保有效连续，所需护理符合临床和定点／目录条件，必要治疗与替代转诊通常及时且净支出可承担；中国公民／长期居住本身不证明这些条件。
4. **残余重要性**：在已发生改进和现实多提供者路径后，原质管、手续、等待及连续性缺陷未形成目标居民当前重要且缺乏可承担替代的必要治疗瓶颈。这个判断仍可推翻，不要求多数患者受害才改档。

**40替代**：当前某必要路径重要质量／费用／等待／断保障碍持续，且现实替代不能缓解，应选40；省中通报与手续限制有反证起点，但仅由旧复杂病死亡、来源冲突或网站挑战不能选40。**80替代**：更强常规／必要专科结果、通常及时可承担转诊及压力下有效备用共同支持，才可审80；不是要求零并发症，也不靠排名、诊疗总量、软件或100%联网升80。**null**：关键范围、延续、有效保险／通常負担或残余重要性不能接受，则保持null，不以有设施／参保人数填60。20无当前严重必要治疗持续不可得的组合依据。

最小待补链不是再加床位或另一复杂病例：一个明确院区、普通参保类别和必要常规疗程的当前过程／支付与转诊执行结果，尤其检验省中实际整改后的护理缺陷或待床转入合格替代。若画像处于断保，先补其类别现行等待规则；否则不为解决所有边缘身份无限扩搜。本轮已经分别尝试常规护理原PDF、当前正式参保／待遇入口、当期结算运行三类直接材料；质量原表已成，公众号内容失败停止同页重复。
