# CCI-2026.10.1：正式证据审查版

证据截止：2026-10-09，Asia/Shanghai。模型保持 1.0.0，数据版本 2026.10.1。

本版正式发布的是有来源的证据审查结果。**它不发布合格的城市数值排名，也不宣称已经完成可用于百年预测的指标数据集。** `published` 是发布状态，`rankingEligible` 是独立的城市评分资格；前者不能覆盖后者。

## 本次完成

- 完成 16 城 × 8 维的 128 项本地证据检索和可用性裁决，合计 130 个不同来源 URL。
- 45 项找到本地原始观察、76 项仅能作背景、7 项证据不足。三种结果均有双语解释、来源期次、访问日期与使用限制。“本地原始观察”不等于其覆盖整个 eFUA，不能自动计入评分覆盖率。
- 实际下载并核对原始 GHSL ZIP；16 城的 17 条选定记录的 ID、名称、UC 集合均匹配；对巴塞尔和雅加达完成 1 km 几何交叠检查，明确并集/单分段选择。
- 页面把本期已完成的来源核查与尚不成立的评分资格分别展示，不再把本期所有城市笼统写成“审核中”。逐城切换同步显示八维结论和来源。
- 8 月快照和 10 月候选快照均保留；本次结果另写入 `CCI-2026.10.1.json`，包括完整城市审查内容并参与输入/输出校验和。

## 未通过的评分资格及处理

完成资料检索不代表资料满足原模型要求。现有 31 个子支柱需要统一定义、评分锚点、完整 provenance 和地理适配；本批年报、测站、单设施、行政区域与国家资料不具备完整的可比 eFUA 覆盖。因而城市 `observedCoverage` 仍是 0%，**它测量的是合格评分输入覆盖率，不是本次检索完成率**。不把数据不足当作城市表现差，也不把其余指标重新归一化生成分数。

| 检查                | 本期审查结论                                                                                          | 模型处理                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 指标注册表和锚点    | 原仓库只有子支柱名称，尚无完成校准的逐项注册表；本批不同口径数值不能直接拼为同一指标                  | `indicatorRegistryComplete=false`，保留资格阻塞                             |
| 来源独立性/替代重算 | 已披露运营商、申办方自报以及共享上游；没有合格 canonical 评分基线，不能计算替代源导致的分数和名次差异 | `alternativeChecksComplete=false`、`sourceSensitive=null`，不伪称敏感性通过 |
| 当前行政区→冻结 FUA | 已审来源仍多为市、州、省、医院或供应网络，未完成统一空间适配                                          | 地方观察不计为全 FUA 城市评分证据                                           |
| 2035—2100 情景      | 当前服务量、病例/试验观察与规划目标不能推导可审计的百年响应函数；没有证据支持所有子支柱沿用零变化     | `futureTransformsComplete=false`，所有未来分数保留 null                     |
| 2125 致命湿热       | 年均气温与单站高温不确定义致命湿热、人口暴露、适应和生存阈值                                          | 证据不足以判定；不标通过/失败                                               |

这些是明确的审查结果，不是已通过的认证。若要发布**数值排名正式版**，下一项实质工作仍是建立和校准逐项指标数据管线、完成空间聚合与来源替代重算；不能仅修改布尔标志或用语言模型给城市估分。

## 复核与发布

`pnpm cci:build` 选择最新年月及修订候选；`pnpm cci:check` 核对不可变输出，并运行模型及证据审查边界测试。`pnpm check` 与 `pnpm build` 是本次发布检查。Cloudflare adapter 不支持 `pnpm preview`，使用 `pnpm exec wrangler dev --local` 验证构建路由；生产通过 main 的 Workers Builds 发布。

自动化与模型辅助检索、翻译不等于独立人工认证；没有人工复核标志的字段仍按机器辅助研究披露。局部来源无法访问、文献截止较早、商业申办方报告或共享上游等限制见逐城记录。
