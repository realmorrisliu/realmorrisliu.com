# CCI 补证：保留八维定义的可行研究路径

核验日期：2026-10-10。本文是证据与方法讨论，不是新增评分规则或排名发布。保留八维含义、权重、历史版本与全部候选；不预留现有城市名额。

## 对此前阻塞判断的修正

“目前没有完整城市测量”不等于“只有改变指数定义才能继续”。可以保留原概念，同时使用城市观察、区域调查、国家背景和明确的研究判断。是否足以比较，要检查证据与概念的关系、空间适用性、来源依赖和不确定性，而不是要求每个概念都存在一张完美的全球数据表。

这也不意味着可以给缺失项统一填中点。国家背景必须标成国家背景；城市间差异需要地方证据；研究推断不能计入实测覆盖。本文提出的证据组织方式尚未转成数值模型，不能据此生成总榜。

资料与限定：

- 医疗：[原论文](https://www.nature.com/articles/s41591-020-1059-1)；[作者数据页面](https://malariaatlas.org/project-resources/accessibility-to-healthcare/)。本轮核实了下载入口和分辨率，尚未下载栅格、检查 NoData、许可与跨期人口加权；因此只是可采集来源，尚非新增候选测量。
- WHO：[GHFD 官方说明](https://www.who.int/data/GIS/GHFD)。页面列出设施 ID、名称、类型、位置等预期字段，明确全球目录尚不可用；国家名录可按实际开放情况逐一核验。
- WGI：[现行方法文档](https://www.worldbank.org/en/publication/worldwide-governance-indicators/documentation)。说明覆盖 200 多个经济体，提供治理估计及模型误差。可采用其背景信息，但不能把来源误差当作 CCI 的完整误差。
- EQI：[官方下载页](https://www.gu.se/en/quality-government/qog-data/data-downloads/european-quality-of-government-index)；[2024 方法论文](https://www.gu.se/sites/default/files/2024-03/2024_2_Charron_Lapuente_Bauhr.pdf)。网站概述与论文的地区数量口径不同，采集时须冻结具体文件和空间版本，不混用概述数量。WGI 自身列 EQI 为上游来源，EQI 方法又涉及 WGI 国家背景：两份总分不能被当成独立证据重复加权，应核查具体版本和原始调查成分。
- LON：[CALERIE 分析](https://www.nature.com/articles/s43587-022-00357-y)。随机试验共 220 人、干预两年；该事后分析发现 DunedinPACE 改变，其他所分析时钟未出现同样结果。论文要求长期随访确认疾病和生存收益。本例用于证据分类，不用于推断当前所有长寿研究均无临床收益，也不构成健康建议。

另有 2026 年医院分层旅行时间预印本，单独审查其分类与代码，见[医院补证记录](cci-global-hospital-evidence.md)。不能因为论文较新，就跳过对 OSM 标注完整性与专科能力代理有效性的核查。

## 怎样用这些证据继续推进

以下为建议采用的研究规则，尚未改动生产模型：

1. **每条证据保留层级。** 记录来源原值、观察期、空间范围、支持的子支柱和缺口。城市、区域、国家与研究判断分别说明；关联到城市不改变原来源的测量尺度。
2. **保留同一概念，检验不同证据。** 医疗旅行时间支持地理可达性，公共服务调查支持治理的一部分；不要要求一个字段回答整个维度，也不要让一个方便取得的字段吞掉剩余概念。
3. **LON 按同一干预追踪完整链条。** 分开记录研究活动、人体试验及结果、临床终点、具体适应证的监管状态、供给和居民资格/费用。试验成熟度可以比较，但不等于承诺延寿；当地没有站点也不等于无法受益于外地开发的疗法。
4. **避免把数据丰富程度当表现。** 更丰富的地方资料应改善判断依据，不自动加分。区域调查缺失需要保留不确定性；研究顺序与是否进入候选总体分开。
5. **先挑战第 32 名边界，再谈固定名单。** 对同一候选范围比较国家背景处理、局部测量及判断假设改变后的入围变化。未校准的研究半宽不能作为排除其他城市的保证界限；若仍存在大量未评估竞争者，结果只能按真实覆盖范围命名。

下一项最具体的数据工作是对两种医疗旅行时间栅格做小规模格式、缺失与空间校验，再决定能否对全候选做人口加权汇总；治理侧先检查 EQI 原始调查与 WGI 的来源重叠。LON 则先建立干预级证据表，避免直接按城市的试验数量排名。这些工作不需要先选择一个新名单，也不要求先降低原八维的含义。

上述为最初讨论阶段的完成范围。随后已完成[医疗栅格核验](cci-healthcare-raster-intake.md)、[全候选人口加权](cci-healthcare-population.md)、[WGI 国家背景采集](cci-wgi-country-context.md)及[统一八维覆盖矩阵](cci-global-evidence-matrix.md)。这些结果没有生成新分数，也没有补齐全球八维排名所需的证据。

## 评分机制复核：数据还不能自动变成分数

2026-10-10 直接核对 `src/cci/model.ts`、`src/cci/judgment.ts` 和[现行研究模型说明](cci-research-model-v2.md)：

- 模型注册了八维、31 个子支柱，但当前研究模式接收的是每城 **8 个维度判断**。`DimensionJudgment` 保存 baseline、uncertainty、trendPerDecade、理由及来源，没有 31 项子分数或子支柱权重。不能在补证时悄悄假设子支柱等权。
- 20/40/60/80 的共同锚点是“严重脆弱／明显约束／能力较强但有短板／强大且有冗余”等定性描述；它们没有给出旅行时间、治理估计等原值到分数的函数。校验器确认分数范围、5 分粒度、来源 URL 和文本存在，不验证来源是否足以支持该分数。
- 当前研究模型没有固定国籍、居留资格、收入、医保或税务身份。MED 的有效就医、LON 的居民可及性及 OPT 的迁移／资产能力因此还缺共同评价对象。不能将这些条件默认为城市名称所对应的国籍或最富裕居民。

因此，后续仍可沿用八维研究判断，不必为 31 项另造评分引擎；但每维需要补一份所有候选共用的证据判读规则。先说明什么证据支持 40、60 或 80，什么反证会降低判断，哪些子支柱缺失会使判断不能确定，再评估城市。原始测量保留原单位，不能将国家百分位、旅行时间或论文数量机械映射到原来的定性锚点。

最小完整的评分记录应在现有理由和证据文件中回答四件事：本维各子支柱分别有哪些支持与反证；这些证据如何对应共同档位；国家／区域信息在哪些地方仍无法区分城市；改变关键假设会如何改变判断。无需为了记录这些内容新增运行时类型。来源多寡不加分，未查到反证不自动成为正面证据。

用户于 2026-10-10 选择分别呈现当地普通居民与跨国迁居者两种视角，暂不合成单一榜单。当地居民口径比较的是不同地方居民实际可得条件；固定身份口径比较的是同一个人在不同城市的可得条件。具体约定见[评分规则的评价对象](cci-global-scoring-rubric.md#评价对象与时间)。跨国人物的国籍、已有居留权、家庭和预算仍待指定；它不阻止当地居民视角继续。两种视角均须按具体服务核验年龄／适应证、医保及税务条件，不能仅凭“普通居民”四字推定所有资格。

下一步先完成共同判读规则和居民口径，再补最能区分档位的证据；不以新增下载数量或表格行数替代可执行评分方法。本次仅复核研究协议，没有修改生产模型、历史分数或发布名单。
