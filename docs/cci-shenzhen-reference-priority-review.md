**制度、资源、医疗、专项转化和技术采用条件60；防护、安全和退出保持未知。** 原权重已知贡献36、未知权重40，数学域36—76，无完整总分。所有评分都依明确的地域、时间及普通居民净取得判断；拒绝必要连接时恢复未知，不取中点或重归一。仅公布本城，不能据此认定全球入围。

## 先确认评估的是哪里

原始GHS-FUA R2019A候选9725的名称为Guangzhou，但它与已评广州9711不同。根独立重算全部9,031几何、修复136个无效形状：深圳中心、人民医院总部、北大深圳医院近似参考点落9725；广州中心在9711，机场参考点在9721。9725面积1,573km²，2015人口不是2026分母。展示称“深圳参考功能区”，保留原始名称及ID，不声称等同深圳行政市、医院患者池或WIPO跨城集群。

南山单点在9724，不能据此说整个南山区都在区外。科苑白石和清华深圳邻域近似点在9724，塘朗山邻域近似点在9725；均为分析者近似点，不是实测道路足迹或服务覆盖。[S03台风处置原文](https://yjgl.sz.gov.cn/zwgk/xxgkml/qt/ztzl/msss/js/gqdf/content/post_12921432.html)记录倒树占道、清障恢复及塘朗山11棵倒树处置，也记有限时段公共服务未受影响。它是实际局部保护，不是仅有机构；但主PCS尚未接受主要自然危险、共享保护对本区普通居民通常后果的整体代表判断，保持未知。可以讨论主要风雨风险及实际适配缓解支持60，不要求每种危险全人口普测。

## 实际交付如何支持五个60

| 维度 | 判断依据与必要连接                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------- |
| ISR  | 实际支付的救助、已经办理的医保服务与前线辅助，有限代表通常执行和适应能力；不是从国家印象或预算推断。                 |
| RES  | 居民水电实际交付、实际消费和资源背景共同支持普通中位家庭水食能通常可管理；市域到本区、均值到普通资源的连接明确可撤。 |
| MED  | 当地综合诊疗、实际临床信息使用及参保操作路径，支持普通必要护理通常可用；活动量和医院等级不单独证明质量。             |
| LON  | 成熟疾病造血重建与当地常规移植服务相接；普通参保付款、等待及反复净照护判断被接受才成立。                             |
| TEC  | 当地持续数据治理、知识产品、临床实际使用和已完成交易形成产用链；未来机器人效果不算已经实现。                         |

[S02统计公报](https://tjj.sz.gov.cn/zwgk/zfxxgkml/tjsj/tjgb/content/post_12803919.html)于2026-05-25发布2025初步统计：居民家庭用水8.46亿m³、生活用电214.96亿kWh，居民人均可支配收入84,945元、消费53,548元、恩格尔系数29.2%，实际低保支付6,130.4万元。这里接受实际居民消费与供给、普通资源背景共同支持通常必要篮子可取得的有限方向判断；不是仅凭水厂运行，也不将均值或低保资格套给中位本人。未测营养充分率、每户账本、全末端水质或全部住房后余额，不把水源达标等同全户安全。与吕贝克未接受普通食品净方向不同，本案采用了同窗居民实际消费与资源的合束代表判断；它仍可撤，不证明两个城市资源孰优。
