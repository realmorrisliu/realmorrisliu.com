# 赫尔辛基 GSS：撤回未闭合的 60 判断

复核日 2026-10-13，证据截止仍为 2026-10-10；对象仍为冻结 eFUA687、当地普通本国公民、中位收入与通常保障。此次只修改 GSS，其他七维不变。依据[共同评分规则](cci-global-scoring-rubric.md)和[Tampere 的统一验收](cci-tampere-priority-review.md)，**原 GSS60 撤回为未知**，不是改成40，也不是证明当地安全能力低。

## 为什么撤回

共同规则的60要求“现实暴力影响较低且具缓解能力，但区域或战略威胁仍重要”。[原主案例](cci-local-2026-helsinki-case.md)的GSS仅引用国家军事预测与地方应急准备：

- [芬兰军事情报2026公开审查](https://sotilastiedustelukatsaus.fi/app/uploads/2026/01/PV_sotilastiedustelu_2026_EN.pdf)属于国家威胁预测，不能测量本地组织暴力的实际影响。
- [赫尔辛基2025年报](https://www.hel.fi/static/kanslia/julkaisut/2026/helsingin-kaupunki-vuosikertomus-2025_EN.pdf)中的演练、民防责任及暴力情境应急组织证明已实施准备；它们不直接证明具体威胁已经缓解、残余影响较低。
- 原JSON本就将organized_violence标为unresolved，regional_conflict与strategic_exposure标为context。不能让一句“日常生活未受广泛阻断”的必要假设承担全部未核实的本地现实影响。

这不是新增“必须全区普查”的门槛。具有明确地点、时点和作用链的有限实际证据，配合可挑战的普通居民适用假设，仍可支持条件判断；但准备能力和国家预测本身尚未完成这条连接。对新候选撤回同类判断后，也须修正既有案例，不能保留历史宽松档位。
