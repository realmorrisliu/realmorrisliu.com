# TEC 知识产出：机构目录与作品计数口径

核验日期：2026-10-10。完整机构目录用于建立可追溯的空间关联，不是城市科技排名或论文产出底表。现有 TEC 网络样本不能替代这一子支柱。

## 本轮冻结的资料

依据 [OpenAlex 官方快照说明](https://help.openalex.org/access/snapshot/)，下载 2026-09-23 版全部 80 个机构分区，合计 202,438,127 字节、136,136 条记录。没有按论文数量、国别、旧榜单或用户提名筛选机构。机构原始数据许可为 CC0；[来源与分区哈希](data/cci-openalex-institution-source.json)保存清单 URL、日期、每个文件的字节数及记录数。

[机构到功能区映射](data/cci-openalex-institution-fua.csv)保留全部机构 ID、ROR、类型、目录状态、原始城市／坐标、父系 ID 和映射状态。[全候选目录覆盖](data/cci-openalex-efua-directory-coverage.csv)保留全部 9,031 个候选。缺坐标、无交集及多重交集分别记录；没有匹配目录点不等于没有研究产出。

本批 120,309 条机构目录点唯一落入候选，15,826 条在冻结边界外，1 条缺坐标；没有多重匹配或无效坐标。3,880 个候选至少有一条目录点，5,151 个没有。所有记录均保留，计数与来源总数一致。

坐标来自机构 `geo`，转换后与冻结 FUA 求点面交集。其精度可能仅到城市，不能视作校园或实验室边界；更不能将全国机构的全部论文计入总部城市。`lineage` 保留供后续父子机构、跨校区与作品作者单位审计，不在本轮累加父子产出。

## 为什么不能直接累加 works_count

[实取接口响应与查询](data/cci-openalex-count-probes.json)保存一次未筛选机构探测及对首条异常计数的后续核查；这是诊断案例，不是代表性抽样。首条机构为 National Institute for Fusion Science (`I4210108322`)：

| 2025 年口径                           |     记录数 |
| ------------------------------------- | ---------: |
| 机构对象 `counts_by_year.works_count` | 18,940,306 |
| 默认 works 语料、精确机构过滤         |    388,273 |
| 默认语料中的 article                  |        256 |
| `corpus=all`、精确机构过滤            | 18,940,301 |
| 全语料中的 dataset                    | 18,099,827 |
| 全语料中的 article                    |        260 |

各作品类型聚合与其响应总数已校验一致。机构汇总与全语料作品查询仍相差 5 条，本轮未确定原因，不能自行修正为一致。第二条机构还包含 `year=10000` 等年份记录，说明不能按数组顺序截取年份或无条件累加。

[官方语料说明](https://help.openalex.org/data/works/corpus/)区分 core、expansion 和 all；[作品定义](https://help.openalex.org/data/works/)涵盖论文、数据集、预印本等不同类型。因此，上述千万级计数不能表述为千万篇论文，也不证明该机构的研究质量或城市科技能力。数据集本身可能有科学价值，问题是不能与论文按条数等价相加。

## 下一步的统一计算约束

- 明确作品类型、语料和年份窗口，再提取作品级记录；2026 年尚未结束，不能将全年 2025 与 2026 年累计量混比。
- 按作品 ID 去重；明确预印本／正式版及撤稿的处理。机构汇总不提供跨机构合作去重所需信息。
- 用发表时作者单位匹配机构及 FUA；父子机构与多城市关联需保留，不能自动归到总部。尚未匹配的作者单位保留未知份额，不重分配给已知城市。
- 合作分摊规则及规模／领域差异尚未校准。目录数量、总引用、h-index 均不直接变成 CCI 分数。

[官方机构说明](https://help.openalex.org/data/institutions/)记录 2026-09-28 更换单位匹配器；本轮机构快照早于该变更，实时 API 探测与快照不是同一版本。后续作品关联必须冻结匹配版本或明确版本不一致，不能静默拼接。

## 复算与边界

研究 Python 使用已有 Shapely、PyProj；网站无新增依赖。将来源清单中的分区下载到缓存，按 `localFile` 命名；来源 JSON 可作为缓存的 `download.json`（脚本读取其中下载元数据）。运行：

```sh
pnpm exec <research-python> -B scripts/cci_openalex_institutions.py --cache <snapshot-cache> --fua <frozen-fua-gpkg>
```

脚本验证分区哈希、逐分区及总记录数、机构 ID 唯一性和 FUA 完整性。原始压缩文件留在研究缓存，仓库保存映射与哈希。当前成果不改变统一矩阵的知识产出覆盖，也未产生城市论文数量、TEC 分数或入围资格。
