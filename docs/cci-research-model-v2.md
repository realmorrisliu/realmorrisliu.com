# CCI 2.0：随证据与事件修订的研究指数

首版：CCI-2026.10.2，2026-10-09。它替代“资料全部符合统计资格才输出结果”的主页面定位，保留 CCI-2026.08、2026.10、2026.10.1 的不可变审查快照。

CCI 是研究判断，不是官方统计、认证排名或准确率已经校准的预测。初始 128 项参考分由模型辅助研究形成，并按跨城共同锚点复核；来源中的观察值与我们的评分是不同的对象。不会通过伪造原始指标或把旧版 D 改成 A 来制造确定性。

## 从依据到分数

每城八维：自然与气候、地缘安全、制度韧性、资源、医疗、长寿转化、科技、全球连接。原有权重保留为 15/15/15/10/15/10/10/10。

1. 结构参考值 baseline：0–100，按 5 分档判断。20 为严重结构性脆弱，40 为明显约束，60 为能力较强但仍有重要短板，80 为强大且有冗余，100 是理想上限。5 分粒度避免伪装成精密测量。
2. 每项附来源 URL、双语理由、不确定半宽及每十年方向假设。国家背景、城市资料、机构与设施记录都可支持判断，但不冒称完整 FUA 实测。
3. 当期中心 = 结构参考值 + 活跃事件贡献。分数截断在 0–100。来源不直接发布这些分值；事件分值是明确的研究解释。
4. 总分按固定维度权重加权。显示一位小数是复算需要，不代表测量精度；小于数分的名次差异不宜作确定结论。
5. “判断把握”由八维基线半宽的算术平均描述：≤10 为较强，≤15 为中等，其余为探索性；维度级只看本维半宽。这是自评研究把握，不是统计置信度。单项薄弱不再否决全部分数，也不把资料缺失当成城市表现差。

LON 同时考虑研究转化、监管与居民可及准备度；研究设施、二期试验或商业诊所不等于已验证延寿。跨城复核压低了仅凭科研生态形成的高分，避免与亚洲城市采用不同尺度。

## 时间与区间

以 2026-10-09 的结构参考为起点，t 为距 2026 年的年数 / 10：

- 中心 = clip(baseline + active event deltas + trendPerDecade × t, 0, 100)
- 半宽 = min(40, baseline uncertainty + 2 × t)
- 保守 / 上行 = clip(中心 ∓ 半宽, 0, 100)
- 总分上下界分别加权各维上下界，采用共同不利/有利假设，没有假装各维相互独立。
- Lifetime 对各目标点作线性插值并计算不折现时间加权平均，当前年等于当前中心值。

每十年趋势（−4 至 +4）与半宽（8 至20）都是显式的判断假设。扩大区间表达长期判断变弱，不声称给出未来概率。模型 2 不使用旧模型 27 情景或 P20/P50/P80 语义；保留 JSON 的 robust/median/upside 字段以兼容界面，页面改称保守/中心/上行估计。旧 schema 中 confidence、observedCoverage、tailTests 等保留的是原统计审查记录，不再作为研究评分门槛；researchModel 与 judgments 是新模式的权威解释。scenarioCount=0。

## 本期事件与变化记录

- 2026-09-16 Copernicus 发布八月与欧洲夏季热状况：四个欧洲城市 PCS −2，按15%权重对总分贡献 −0.3。区域信号支持方向，2 分幅度是研究判断，不是当地热损失数据。结构参考不重复扣本条事件。
- 2026-10-08 ER-100 早期人体试验公告：波士顿 LON +1，总分 +0.1，仅反映当地申办方生态的转化活动，不加 MED、不推断延寿，也不声称试验覆盖全市。

本期首次建立分数，因此“事件调节”是相对结构参考的贡献，不是相对 CCI-2026.10.1 的涨跌。其他九条研究更新中的背景资料可支持基线；没有足够新增解释力的新闻不强行加减分。

后续发布步骤：

1. 核验事件的发生/公开日期、来源、影响城市及维度；新增唯一 event ID、分值与理由。更新日期不得越过发布截止日。
2. 每个候选保存完整的活跃事件集合；引擎从结构参考重算一次，不把上一版已调节分数再次作为起点。
3. 事件被证伪、消退或纳入新基线时，在新版本移除/调整该条并写明原因。基线重估须解释来源或结构变化，避免同一事实在 baseline 与事件层重复记分。事件不会无依据地自动衰减。
4. 写入新的发布 ID 与校验和，保留旧快照。至少检验事件单次计入、日期与数值边界、权重、区间、时间聚合和中英文页面。

本次实现的是可维护、可复算的版本工作流；没有创建无人值守新闻监听或自动发布任务。
