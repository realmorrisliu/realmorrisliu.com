# 纽约功能区 GSS：实际受害、处置与跨州通道复核

证据截止 2026-10-10；查阅 2026-10-12。对象为美国公民、通常长期居住、当地中位收入及通常医保，冻结 eFUA 7244。沿用[共同档位](cci-global-scoring-rubric.md)与[华盛顿](cci-washington-security-review.md)、[大阪—京都](cci-osaka-kyoto-security-review.md)的推定层级，仅研究 `organized_violence`、`regional_conflict`、`strategic_exposure`；不新增事件阈值，不将普通犯罪总量直接当组织暴力。

**独立建议 GSS 条件性 60。** 新证据补到实际投向人群的危险、宗教场所受害、跨州组织暴力后果、现场控制／排爆／有限撤离后的返回，以及跨州主要活动通道已经运行的复盘。由此有限推定主要应对可运作、通常生活与关键通道未因所审威胁形成广泛持续阻断；不是全区年度低风险率、所有群体安全或完美防护的测量。拒绝下列时间、范围、通常触达和未观察影响假设，必须恢复未定。

## 三个子支柱及整体档位

`organized_violence`：BB7、Sotomayor、Crips 提供组织关系、实际受害与已执行调查／拘捕／审判的不同证据，补足只看单一未遂计划的不足。一般犯罪下降不参与选档，单人偏见袭击作为实际战略／目标群体后果保留，但不靠猜测赋组织成员身份。

`regional_conflict`：现有伊朗冲突警戒、被指跨境会堂计划和共同应对连接到本地目标；不是从“美国没有本土战场”给高档。Gracie 案原记者会明确未确认与伊朗联系。未取得全功能区区域外溢造成的必要服务／通道损失普查，未知不当零，也不因国籍、宗教或移民身份推个体危险。

`strategic_exposure`：市长住宅附近、会堂、国际活动与跨州交通节点确有风险或已执行防护；有限撤离后返回、同场礼拜继续、实际反无人机及跨州通道运行是正向实绩。装置未严重伤人含偶然因素、居民反复受威胁、非帮派受害者永久伤害和活动通行约束共同阻止简单高档。

条件性 60 必须同时接受：

1. 三月现场处置、五月／六月调查和七月跨州协调直到截止日仍能代表主要应对可运行；不把 July4 或 UNGA 的事前部署当独立完成证据。
2. 所审后果及恢复对普通居民通常生活／主要通道具有有限代表性，未观察部分尚无足以改变整维的重要持续阻断。特定社区受害、恐惧与心理后果仍可能推翻该判断；收入／国籍不保证获得同等保护。
3. 当前有限地点与跨州运行可作 eFUA 7244 的有条件适配；NYC 五区、NYPD、NJ 全州、港务局和司法辖区均不等于本候选。父研究已核验 Gracie Mansion、Central Synagogue、Newark 近似参考点独属 7244；仍非精确案发点、所有命案／全走廊或整个 CT 部分覆盖。

保持已有五项 60、PCS／RES 未定时，GSS `60 × 15% = 9` 使部分数学域从 36—76 变为 **45—70，无总分中心**；仅撤回 GSS 回到 36—76。真实新证据若支持 GSS40／80，则在其余当前判断不变时为 42—67／48—73。数学域不是可信城市上下界、概率或排除竞争者的依据。

下一条最能改变档位的证据是：反复受威胁社区和必要通道的当前剩余约束、实际保护触达与恢复，尤其通常居民画像及 NY／NJ／CT 未覆盖部分。再增加近似的起诉条数不会自行提高可信度。
