# CCI 全球 Top 32：从全量候选产生排名

决策日期：2026-10-10。用户明确选择“按 CCI 八维表现选出全球前 32”。本文件取代后续发布沿用固定 32 城的选样规则；已发布的历史研究样本及其快照不改写。

## 目标与当前状态

32 是排名输出数量，不是研究对象的预先名单。原 16 城、扩展后的 32 城和用户提及城市均没有保留名额。地域均衡、人口、GDP、知名度及其他城市榜单名次不作为 CCI 准入或加分条件。全球代表性抽样与最高分排名是不同目标，本轮采用后者。

**居民视角决策（2026-10-10）：** 用户选择当地普通居民与跨国迁居者分别评价，暂不合成单一榜单。两种视角均保留原八维权重、2026 年中心估计及全量候选，各自产生和审查 Top 32；不会用当地居民榜的入围名单限定跨国榜。当地口径为本国公民、当地中位收入和通常医保；跨国口径的国籍、已有居留权、家庭和预算待指定。具体事实、资格与共享证据规则见[评价对象](./cci-global-scoring-rubric.md#评价对象与时间)。

目前尚未得到全球 Top 32。CCI-2026.10.3 是 32 城研究判断，不能改名为全球榜单。新增 128 项维度审查中，105 项是背景证据、5 项证据不足；18 项可保留观测也不一定覆盖整个功能区。扩大候选库并不会自动改善这些分数的证据基础。

**最新证据入口：** [统一矩阵](cci-global-evidence-matrix.md)已接入 2026 Q3 网络样本，8,255 个候选有局部网络证据、776 个缺样本；这不构成完整 TEC。另已完成 [OpenAlex 全机构与作品来源核验](cci-openalex-institutions.md)：136,136 条机构目录、2,040 个作品分区的全部页脚均已对账。[全量年份筛选审计](data/cci-openalex-filter-inventory.json)核验 45,069,447 条 2025 年记录及同数唯一 OpenAlex ID，其中含 25,158,414 条 dataset，不能统称论文或视为成果版本已去重。作者单位提取仍在分阶段运行，单分区连接已验证，尚未完成全库城市归属。两类资料均没有生成全球协议下的城市分数或入围资格。

后续计算依次需要全量作者单位提取及对账、地点歧义和未知贡献处理、知识产出指标校准；此外仍须补足其他维度。科研作品提取完成也不能单独完成八维排名。下文各阶段记录和原始审计快照保留其当时状态，不作为最新完成声明。

**OPT 设施目录已接入：** [全量机场核查](cci-ourairports-transport-evidence.md)冻结并校验 86,231 条 OurAirports 记录，将点位与全部 9,031 个候选匹配。3,094 个候选有区内目录点，其中 1,338 个有定期服务且非关闭标记；5,937 个无区内点不代表不能出行。8 条关闭／服务矛盾保留待查。完整矩阵已接入目录数量，尚不证明实际航班、居民接驳、费用或替代通道，更不是完整 OPT 或入围资格。

**评分优先级已调整（2026-10-10）：** 用户要求从资料扩展转向统一评分、全量筛查和入围审查。第一版先做 2026 年当地普通居民视角，暂以全部 9,031 个冻结功能区作为明确声明的第一轮范围，证据截止日为 2026-10-10；这不解决较新中心覆盖或替代全球目标。[评分校准](cci-local-2026-scoring-calibration.md)已对三个完整给定能力情形实跑八维总分、单维反事实、未知不填值和权重敏感性；另已形成[新加坡](cci-local-2026-singapore-case.md)及[伦敦](cci-local-2026-london-case.md)真实案例，八维条件性总分均为 58；另形成[赫尔辛基](cci-local-2026-helsinki-case.md)条件性 60 案例，三城各 31 项均审阅但未均充分测量。赫尔辛基检验可信人体结果到居民服务的有限连接，MED 40 的条件情景使其变为 57，故小分差不支持确定优劣。两城采用同一判读边界并实算联合假设与权重情景；同档不代表实际能力相等，尚未证明跨研究者一致性。LON 代表性及其他居民触达／压力运行假设仍需挑战；案例不是已核验全球名次或竞争者排除界限。现有矩阵的提前排除审查已接入（见下文），下一项推进全量候选的实质八维评价并优先补可能改变入围判断的未知项，不以继续新增类似代理数据替代成绩单。三城只用于校准，没有入围名额。

### 已执行的证据盘点

已按候选 ID 关联 CCI-2026.10.3 的全部八维审查，生成[全量覆盖矩阵](./data/cci-global-coverage-2026-10.csv)及[计数与输入校验和](./data/cci-global-coverage-2026-10.json)。矩阵中的八维状态引用该历史发布的审查和来源，不表示已完成新的全球统一评分。

- 32 个历史研究对象关联 33 个 eFUA：31 个单功能区，巴塞尔另为两个功能区的并集。并集成员只引用同一项研究，不分摊或复制其分数、原始指标。
- 8,998 个 eFUA 在该发布中没有研究记录；`not_researched` 不是低分。
- 32 个对象的观测空间适配审查均为 `unresolved`，结构化 `indicators` 合计为 0。来源中有可保留观察，不等于已形成可统一计算的完整城市指标。
- 256 项历史维度审查中，63 项为 `usable_observation`、181 项为 `context_only`、12 项为 `insufficient_evidence`。这些是研究对象的去重计数，不按并集成员重复累计。

生成器使用 Python 标准库，仅作离线数据盘点，不进入网站的 Node 构建流程：

```sh
pnpm exec python3 -B scripts/cci_global_coverage.py --check
pnpm exec python3 -B scripts/test_cci_global_coverage.py
```

生成前校验候选 CSV 的 SHA-256、行数、唯一 ID、引用完整性和八维审查。测试覆盖并集不复制、未知状态不记零、输入存在不自动证明边界适配，以及错误映射拒绝。

新版 UCDB R2024A V1.2 已下载并导出 16 张属性表，保存了[原文件及逐表校验和与字段清单](./data/cci-ucdb-r2024a-v1-2.inventory.json)。主表实查 11,422 个唯一城市中心。NaturalSystems 表存在 11 条额外重复 ID 记录，且部分水与洪水字段的字典和实际字段不一致，未将其直接用于评分。下一步是对城市中心与冻结 eFUA 做空间匹配、核查适用指标的单位及缺失值；不能以名称匹配或非空单元格数量替代空间适配和证据质量。

**空间核查已执行：** [完整计算记录](./cci-global-spatial-audit.md)得到 9,743 对正面积交集；1,861 个新版中心完全不与旧功能区相交，153 个与多个旧功能区相交，1,156 个旧功能区没有新版中心相交。该证据表明必须处理候选覆盖与边界迁移，不能直接把新版中心指标按名称塞入旧功能区，或忽略未匹配中心后声称全球前 32。下一步是指标语义与缺失值核查，以及边界迁移规则。

**WUP 2025 覆盖复核已执行：** [完整矢量核查](./cci-wup-2025-crosswalk.md)从官方 V1.1 多时期包筛出全部 12,140 个 2025 年中心，与冻结 FUA 得到 10,060 对正面积交集；2,280 个中心无相交、164 个涉及多个 FUA、997 个旧 FUA 无中心相交。这与上述 UCDB 结果属于不同来源版本，不能将未匹配数相加或相减当作新增城市数；WUP 与 UCDB 的直接空间连接已完成：889 个 WUP 中心无 UCDB 交集，其中 559 个也无旧 FUA 交集；完整对应表保留多对多关系，实体迁移规则仍未确定。

**字段核查已执行：** [数值质量报告](./cci-global-field-audit.md)扫描 16 表的 2,910 个表—字段组合，区分空值、零、文本、非有限数及冲突重复；[31 子支柱语义规则](./cci-global-indicator-contract.md)明确已核验资料只能提供 10 项局部代理，另外 21 项没有相应城市测量。没有完整测量项，不将非空率或代理数量冒充 CCI 覆盖率。洪水重现期、冲突死亡数与网络字段的字典歧义列为待核查事项。

**原始事件补证已执行：** [UCDP 全候选计算](./cci-global-violence-exposure.md)对 2021—2025 年 121,587 条事件逐条处理，将 33,099 条精确地点且唯一归属的合格记录关联至 993 个 eFUA；全部 9,031 个候选均输出记录。定位粗糙、框架外及数值异常的事件单列，不把未归属当作零风险。这是 `organized_violence` 的部分历史证据，没有生成 GSS 或 CCI 分数。

**制度韧性国家背景已采集：** [WGI 2026 版实查](./cci-wgi-country-context.md)取得 2025 年六维综合估计、标准误及 90% 区间，共 1,279 条经济体—维度记录；9,019 个候选可关联六项背景，12 个有缺项。国家表与城市引用分开，不把国家值变成城市治理实测；受限上游来源均值不导出，未生成 ISR 分数。

1. 八维及权重沿用现有模型：PCS 15%、GSS 15%、ISR 15%、RES 10%、MED 15%、LON 10%、TEC 10%、OPT 10%。不为得到预期城市名单调整权重。
2. 首次筛选工作口径暂用页面当前的 **2026 年中心估计**，统一证据截止日；它是工作默认值，不是用户另行选择的长期预测目标。2035—2100 年及 Lifetime 各自排名，不沿用一个固定 32 城池来宣称所有年份的全球前 32。
3. 先定义每个子支柱的指标、方向、锚点、适用边界、时效及缺失处理，再对全部候选应用。保留来源值、转换与研究判断的区别；任何权重或锚点变更须形成新模型版本。
4. 数据缺失不记零、不自动落榜，也不把国家指标复制成城市实测。跨市创新集群、医院和试验站点必须去重并匹配边界；科研能力不能直接代替居民医疗或长寿技术可及性。
5. 所有候选保留状态和原因：尚未评估、证据不足、已评估。现有研究分可保留为历史线索，但不能跳过统一尺度复核获得优先资格。

## 如何判定确实进入前 32

仅在有资料的城市中取最高 32，会再次引入数据可得性偏差。因此必须披露全量候选的覆盖矩阵和未解决项，不得隐去尚未评分的城市。

可以分阶段采集，但人口或别人的榜单只可帮助安排工作顺序，不能排除候选。若用界限提前排除某城，界限必须由统一指标规则推出；缺失维度不能假定为低分。未评估城市仍可能超过第 32 名时，只能发布“已评估城市中的前 32”，不能声称全球前 32。

现有模型的研究半宽不是统计置信区间，也不是保证上下界，不能直接用于证明某城不可能入围。第 32 名附近应显示分数差、证据缺口及权重／假设敏感性；并列及名次不稳定须明确披露。固定展示 32 行时，技术排序规则不代表第 32 与第 33 名存在实质优劣。
