# Saifai 8299：未知探索队列的有界八维复核

**本轮没有形成可回填的八维中心分。PCS／GSS／ISR／RES／MED／LON／TEC／OPT的主判断均为`null`；MED存在明确附加假设下的60替代，但通常中位收入居民的后续必要治疗保障尚未闭合，不能直接采用。** 这是有界研究后的能力未知，不是低分、排除或“小城表现差”。已取得真实热应对、医院当前服务／初始免费急救、当地经办会纪、临床护理、地下水原表及转化／科技活动；它们比短旅行和快测速更能说明待检假说，也暴露了空间、分母及支付连接的限制。

## 最有辨别力的已发生事实与反证

**热和防护。** [UPSDMA《Action Taken Report Heatwave Management2024》](https://upsdma.up.nic.in/2024/HATR2024.pdf)是真实应对回顾，不是仅未来行动计划。PDF p8–9表为2024春夏站点热浪日，Etawah May4／June1、共5日；p11原表May29和June17均45.4°C。站点不是8299户内或湿球测量，不能给本区相同精确温度。p51县级回顾报告24h控制室、在县内设置冷饮／ORS柜台、识别修理乡村手泵、毛巾／伞发放、2,262 master trainers、全469Gram Panchayat讨论和医院人员识别／处理热病训练，兼有未完成池塘修理的指令、可用水车和选举cool-roof安排。已实施项目与“要求做”分开；全县活动不能证明所有Saifai劳动者、老人或家庭有降温及持续供水。热记录／应对可支持方向，不是“死亡为零”或恢复结果。

**洪水和地质。** [ISRO/NRSC、NDMA与UPSDMA联合《Flood Hazard Atlas》](https://upsdma.up.nic.in/2024/Flood%20Hazard%20Atlas%20of%20Uttar%20Pradesh.pdf)版本1.0，April2022。方法为139幅卫星数据和1998–2020累计淹没，表11标题另写1998–2019，保留窗口标题不一致。p65 Table19 Etawah面积231,100ha、累计淹没37,416ha、约16%、其自定义FHI16；不是本区16%人口风险、2026灾损或CCI16。源明确未被卫星捕获的洪水可能漏记。冻结4km²尚未与具体洪水图／排水设施适配，不能由县整体低频类别推局地安全。地下水报告的冲积地质和参考岩石PGA不补抗震、沉降、雷电／强对流或野火保护。没有把普通住宅／医院消防事务当野火。

**地下水：重要原表冲突。** [CGWB原2022 Etawah NAQUIM报告](https://cgwb.gov.in/cgwbpnm/download/891) p37明确**2021 pre-monsoon每个block office的IM-II手泵一份、全县共8样本**，不是每block8份或全区住户。p38 Table13原Saifai行Mn**0.039ppm**、Fe0.306ppm、U0.028ppb；p73 Table62区块摘表却Mn**3ppm**、Fe0.31ppm、U0.02ppb，正文称重金属合限。两表已目视，不静默把3改0.039，也不据更坏摘表直接给当前RES40；需要重测／勘误与实际水源适配。p71报告Saifai block两口监测井，2021 pre-/post水深约11.375／11.51mbgl，2012–21趋势下降0.239／0.414m/年；March2020抽取比例35.36%“Safe”仅资源利用分类，不是饮水安全或未来保证。没有把未实施recharge计划的预测33.60%当已改善。即便修好手泵，也不是化学合格／到户持续服务。
