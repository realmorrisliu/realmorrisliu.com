# Apia：新版候选的有界身份核查

**Apia仍作为未解决竞争者保留；本轮确认来源身份及统计范围差异，尚未定义可与旧功能区比较的通勤单位。** 审阅2026-10-13，研究证据截止2026-10-10。它是既定探索队列的`ucdb:1`，不是旧FUA1 Herat，也不因新来源ID靠前获得高分或入围资格。

## 已核结论

| 对象                      | 本轮实际核验                                       | 可支持的结论                                                         |
| ------------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| UCDB R2024A V1.2 `ucdb:1` | 名称Apia、Samoa；2025模型人口60,041.65661；35km²   | 一个明确的模型城市中心，尚不是通勤功能区                             |
| 旧GHS-FUA R2019A          | 重新读取全部9,031几何，与目标无正面积交集          | 不能继承旧城市分数；不证明城市新建或不存在居民联系                   |
| WUP R2025A V1.1           | 独立遍历全部12,140个2025中心，与目标亦无正面积交集 | 两来源并非同一中心全集；不能用另一来源无匹配排除Apia                 |
| Samoa 2021普查AUA         | 第16页按四个政治区定义；第19页合计35,974人         | 行政统计单位；不能与2025模型数直接比较人口增长                       |
| Samoa 2023环境报告AUA     | 第165页边界图、167页约150km²及未来扩展方向         | 规划口径与模型中心、普查定义尚未完成对应，扩展预测不是已实现通勤范围 |

[官方普查原件](https://www.sbs.gov.ws/documents/census/2021/Census_2021_Final_Report.pdf)列Vaimauga 2、3、4及Faleata 1；[官方环境报告](https://www.mnre.gov.ws/wp-content/uploads/2024/09/Final-Samoa-SOE-2023-v39-digital-1.pdf)图题使用Vaimauga East/West、Faleata East/West。主任务目视上述四页，保留版本及边界差异，没有把政治区名称自动互换，也没有把CBD、行政AUA、模型中心当同一居民分母。

两轮定向定位后停止扩搜。本轮未取得这些边界的权威版本对照、通勤流或可实施的居民服务圈映射。因此**不建立新FUA、不合并相邻区域、不增加已完成城市数、不填任何八维分数**；原4,141条未匹配记录及2,432复核组不变。不是认为Apia能力不足。

## 身份与复核记录

[结构化记录](data/cci-apia-identity-review.json)保存三套地理来源SHA、全集数量、模型属性、投影边界、目标WKB哈希、原件字节及页码。普查PDF为2,776,136 bytes、SHA `59fd92c6e36f379949915dc2f7d142bd4c54a037497044be6a7befab3de1ddbc`；环境报告字节身份见记录。报告年份和URL目录日期不冒充独立核定的首发日。

空间复核复用`cci_global_crosswalk.load`及`cci_wup_crosswalk`来源常量：验证冻结来源SHA、ESRI54009、唯一目标ID；全集正面积交集，WUP仅2025。无效多边形只在面积、范围和类型不变时修复，14个WUP修复ID记入记录；确认9,031/11,422/12,140行数及两个空交集结果。分析者代表点仅用于识别，不当市中心、院区或居民服务地。没有修改原跨来源表或优先模型的冻结快照。

最小重开证据是**官方边界版本及对应关系，加真实通勤或居民服务联系**。这比继续搜同名城市人口更能解决排名单位问题。随后再按共同八维判档，不能把本轮身份核查冒充完成全球覆盖。
