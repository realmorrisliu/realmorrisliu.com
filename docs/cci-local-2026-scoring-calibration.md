# CCI 第一版当地居民评分：锁定口径与校准演算

决策日期：2026-10-10。采用用户提出的四步发布路径，当前工作重点从扩展资料数量转向统一评分与入围证明。本文先锁定第一版口径，并用完整、明确给定能力的对照案例检验评分和敏感性；真实城市还需逐项形成有证据的判断。对照案例不是城市成绩单，不授予真实候选排名资格。

## 第一版口径

- **时间**：2026 年当前中心估计；证据截止日为 2026-10-10，仅使用截至该日已发布并实际核验的资料。采集年份不替换观测年份，不将未来设施或试验公告计作已实现能力。
- **居民**：本国公民、通常长期居住、当地收入中位水平及通常医保条件。支付能力比较必须注明收入统计单位和时期；工资中位数、家庭可支配收入与等值人均收入不混用。治疗的年龄、适应证和其他资格逐项列出，不假定居民满足罕见病或试验入组条件。
- **第一轮候选**：全部 9,031 个冻结 GHS-FUA R2019A 功能区。来源、唯一 ID、边界和校验和见[候选协议](cci-global-top-32.md)。这是明确声明的旧功能区范围，不是已经解决当前全球覆盖；新版中心的未匹配项继续保留为全球目标待核验竞争者。
- **模型**：PCS/GSS/ISR/RES/MED/LON/TEC/OPT 权重为 15/15/15/10/15/10/10/10，直接沿用生产模型；31 个子支柱不新增等权平均。不合并跨国迁居者榜，不把旧 32 城作为名额或标尺。
- **阶段**：既有提取任务可完成和验收，但下一项评分工作先完成真实八维案例，不把继续增加类似代理资料当作替代交付。

允许研究判断，不要求每个输入都是同年城市实测；但必须区分本地观测、国家／区域背景、研究假设，以及影响整个功能区推断的地理限制。资料不足不扣分；证实的居民服务或信息障碍可以成为相关维度的反证。

## 将共同档位用于实际判断

沿用[八维档位](cci-global-scoring-rubric.md)，首轮先用 20/40/60/80，暂不为案例之间凑出次序使用 5 分差异。维度仍整体判断，以下是判读条件，不是子支柱加减分表：

| 档位 | 操作判断                                                                 | 不能这样使用                                                |
| ---- | ------------------------------------------------------------------------ | ----------------------------------------------------------- |
| 20   | 有证据的持续或严重基本能力失效；明确影响居民、范围、缓解为何不足         | 因资料少、没有注册记录或国家贫困直接给 20                   |
| 40   | 有证据的重要居民约束，替代路径不能充分解除；其他局部优势没有消除本维瓶颈 | 看到任何负面记录便自动把整个维度降到 40                     |
| 60   | 主要能力有依据，重要服务通常可得，但仍有具体短板或未证实的压力冗余       | 按未知项统一填 60，或默认所有中等收入居民都享有平均能力     |
| 80   | 相关子支柱的强能力、居民实际触达和必要备援均有依据；共同失效已经检视     | 因医院近、科研强、机场多、无冲突记录或制度文件齐全直接给 80 |

如果事实不足以选择一个档位，维度判断可以待定；如果中心判断依赖明确假设，必须同时提供可改变档位的条件性替代判断。替代档位是敏感性设定，不是覆盖全部未知的保证上下界。研究假设必须有能力依据，不能给任意未知项指定一个“保守中点”。

## 三个完整的能力对照案例

**以下三个案例均为人为完整指定的校准情形，不对应任何实际城市。** 它们检验相同能力条件能否得到相同判断，以及不同短板是否按原权重影响总分；不能证明真实评估者已达成一致。

| 维度           | A：医疗近而必要治疗不可负担，科技广泛强                                        | B：科研强而居民技术扩散受限                              | C：多类能力强且有备援，长寿采用仍受限                            |
| -------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------- | ---------------------------------------------------------------- |
| PCS            | 60：主要危险与防护有依据，压力下仍有短板                                       | 60：同 A                                                 | 80：相关危险低暴露或有效防护与压力运行均已核验                   |
| GSS            | 60：主要安全能力可运作，外溢或战略短板仍在                                     | 60：同 A                                                 | 80：低现实影响有覆盖依据，区域／战略威胁及应对均已检视           |
| ISR            | 60：执行和主要服务有结果，部分触达及恢复仍薄弱                                 | 60：同 A                                                 | 80：执行、适应、群体触达及恢复有结果与备用资源                   |
| RES            | 60：日常供给可靠，关键来源仍有短板                                             | 60：同 A                                                 | 80：基本供给可负担且替代来源能应对共同冲击                       |
| MED            | 40：医院近且质量高，但中位居民无法承担必要治疗，通常保障和替代服务不能解除障碍 | 60：常规与必要专科可得，仍有等待或压力运行短板           | 80：资格、支付、质量、专科转诊和持续服务均有结果与备援           |
| LON            | 40：已核实的研究到适用人体结果／监管／居民获得链条存在明显断点                 | 40：同 A；科研强不解除已核实断点                         | 60：可信人体证据与转化路径存在，但成熟度或普遍可得性仍受限       |
| TEC            | 80：持续知识产出、产业连接、数字设施及广泛采用均成立，关键能力有多节点         | 40：知识产出强，但居民和主要行业采用有重大且未缓解的断层 | 80：同 A                                                         |
| OPT            | 60：指定居民有多类可用通道，但资格、容量或共同失效仍有短板                     | 60：同 A                                                 | 80：交通、合法迁移、资产和通信路径实际可用，替代与共同失效已检视 |
| **原权重总分** | **57**                                                                         | **56**                                                   | **78**                                                           |

A 的医疗低档来自已指定且已核实的必要治疗障碍，不来自医院价格“看起来贵”；如果只知道医疗近而不知道支付条件，不能套用 A。B 的技术低档来自已核实的重大扩散断层，不来自未找到扩散数据。C 的 LON 60 表示准备度与采用限制，不承诺延长一般人的寿命。

### 实跑的反事实与敏感性

- **解除 A 的必要治疗支付瓶颈**，并确认达到 MED 60 的其他条件：总分由 57 升至 60；只影响 MED，不顺带给 ISR 或 LON 加分。
- **仅增加 B 的论文或科研机构数量**，居民采用断层仍在：TEC 不自动升档，总分仍为 56。不能把科研热度重复计入 LON。
- **同一接诊信息障碍**已经通过实际影响计入 MED 时，不再仅因同一障碍给 ISR 追加扣分；独立的公共问责缺陷需要独立依据。
- **A 与 B 的 1 分差不稳定**：仅在敏感性演算中将 TEC 的 5 个百分点转给 MED，保持权重和为 100，A/B 变为 55/57，次序翻转。这没有改变正式权重，说明小分差不支持确定优劣。
- **A 的 MED 改为真正未知**：固定其他给定维度，MED 全范围 0—100 时，总分只可界定为 51—66，中心值为空；不能填 50 或 60，也不能沿用原 40 排除竞争者。这个界限仅对给定的对照条件成立，不是实际城市的保证界限。

结构化输入见[校准案例](data/cci-local-2026-calibration.json)，计算和反事实检查见[演算脚本](../scripts/cci_local_score_calibration.ts)。脚本从 `src/cci/model.ts` 读取原权重，并拒绝不完整维度、重复案例 ID、越界分数及没有说明的案例；自身检查缺失不产生中心值及单维变化只产生该维的加权影响。它不自动判断现实城市证据属于哪个档位，也不检验文字理由是否充分。

```sh
pnpm exec node --import tsx scripts/cci_local_score_calibration.ts
```

## 全量筛查与发布门槛

筛查安排补证顺序，不能按人口、资料量或名气删候选。真实案例形成后，用相同记录和判断规则推广，先保留未定项；只在有适用证据形成可辩护排除界限时停止深入调查。条件性替代档位和旧研究半宽不能当作这类界限。

审查第 32 名附近必须同时包括未深入评估但仍可能入围者，记录更换合理假设、缺失处理和权重敏感性是否改变名单。仅对部分城市完成评价时只能发布“已评估城市中的 CCI 前 32”；声明的全部候选已评估或其余有依据排除时，才可发布“该候选范围内的 CCI 研究前 32”；新旧覆盖差异及遗漏竞争者也完成审查后，才可使用“全球 CCI Top 32”。

本次已经完成完整给定能力案例的计算及反事实演算，尚未完成上述两座真实城市的八维统一成绩单，不能把这些对照分数写入城市榜单。下一项必须是完成真实案例判断及其敏感项，不能以新增来源清单替代。
