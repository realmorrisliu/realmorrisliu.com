# CCI 新版城市中心：旧功能区的人口覆盖核查

复核日 **2026-10-12**，沿用证据截止 **2026-10-10**。本轮对全部 **12,140 个 WUP 2025 中心**计算原生人口网格覆盖，旧候选仍为完整 **9,031 个 GHS-FUA R2019A**。

**4,936 个中心有抽样模型人口落在旧功能区全集之外。** 其中 2,280 个完全没有旧 FUA 正面积交集，2,656 个同时有区内和区外抽样模型人口。“有交集”不足以证明居民均已覆盖；这不是 4,936 座新增城市，也不是已有候选落榜证据。全部竞争者继续保留，八维评分、可靠排除界限与全球入围资格没有因此建立。

## 来源与计算口径

[JRC 原人口产品](https://data.jrc.ec.europa.eu/dataset/adba95af-db56-4569-acd3-9513201eba30)将 2025—2100 定义为 CRISP 投影人口，基于 2000—2020 地方增长并向国家预测趋同；不是 2025 普查或 2026 当前实测。元数据首发 2025-11-17、修改 2025-12-04；自动引用栏年份不证明新版人口观测。原件与栅格元数据见[已冻结人口来源](data/cci-healthcare-population-source.json)，矢量及旧 FUA 见[WUP 全量相交审查](cci-wup-2025-crosswalk.md)。

1. 校验完整矢量 ZIP 的 SHA、CRC、投影、全部中心—年份唯一身份与历元行数，并核对全部 12,140 个 2025 中心及原相交底表。
2. 每个中心与所有有正面积交集的旧 FUA 相交，先合并覆盖几何，避免一个网格因多个 FUA 被重复计入；面积份额与冻结底表对账。
3. 原 Mollweide 边界按 1,000 米加密后转 EPSG:4326，使用人口原生 30 角秒网格。只选网格中心点在城市中心内的单元，整格人口按中心点是否在覆盖几何内分为区内／区外；没有重采样栅格或假设人口密度均匀。
4. 掩码、负值、非有限人口保留未知单元计数，从已知人口份额分母中排除；来源真正的零可保留，但全零不解释为无居民。逐中心检查区内＋区外＝已知总量，非有限合计拒绝。
5. 全部几何审查、栅格外及裁切状态保留；不把失败算作零覆盖。没有跨中心求人口总和，也没有将中心变成通勤功能区或居民画像。

结果[逐中心 CSV](data/cci-wup-2025-population-coverage.csv)及[版本、方法、SHA、运行时与计数 JSON](data/cci-wup-2025-population-coverage.json)可独立复核。全部 12,140 中心取得正的已知模型人口，本轮选中网格中未见未知人口单元；这仅描述已选网格，不证明输入模型没有误差。14 个来源无效多边形只在修复不改变面积、范围及多边形类型时接受，ID 明列于 JSON。

**另有 59 个中心虽有旧框架外面积，却没有抽样的框架外正模型人口。** 这不证明区外无人居住，粗网格与中心点整格分配可能遗漏小范围人口；它明确说明面积覆盖与此人口抽样不能互相替代。

## 南京的实例与适用限制

冻结南京 eFUA 9701 有四个 WUP 中心相交，其中 WUP 11254 同时与两个旧 FUA 相交。它的面积覆盖约 98.7552%，按旧 FUA **全集的并集**计算已知模型人口覆盖约 99.7466%，约 17,058 个模型人口位于该全集之外。覆盖人口不能全部归入南京，也不能称为南京普通居民覆盖率。另三中心在本次整格抽样中没有旧框架外正模型人口，同样不表示实际全覆盖。

这些是投影居住人口，不区分公民、收入、医保、患者、实际服务使用或通勤身份；不能用作评分分母、城市合并／拆分、服务继承或能力排除证明。较新中心的独立城市身份、与旧功能区的真实关系及其八维表现仍需核查。本轮完成的是全量居民覆盖的模型检验，而非候选迁移。

## 复算与检查

使用已有研究环境的 NumPy、rasterio、pyproj、pyshp 与 Shapely，未增加网站运行依赖。原件路径仅为本地复算示例：

```sh
/private/tmp/cci-global/geo-venv/bin/python -B -m unittest discover -s scripts -p 'test_cci_wup_population_coverage.py'
/private/tmp/cci-global/geo-venv/bin/python -B scripts/cci_wup_population_coverage.py \
  --archive /private/tmp/cci-global/GHS_WUP_MTUC_GLOBE_R2025A_V1_1_vector.zip \
  --fua /private/tmp/cci-geo/GHS_FUA_UCDB2015_GLOBE_R2019A_54009_1K_V1_0.gpkg \
  --population /private/tmp/cci-global/GHS_WUP_POP_E2025_GLOBE_R2025A_4326_30ss_V1_0.tif
```

三个测试检查缺失／零与溢出、面积一半却仅覆盖十分之一人口、无数据／框架外／裁切状态。真实全量运行后另对全部行复核身份、分区守恒和份额。矩阵接入校验和与范围证据，中英文研究区呈现结果，旧 9,031 候选的单位、评分与历史发布保持原义。
