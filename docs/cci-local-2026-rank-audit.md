# 全候选入围可判定性：条件分数不能替代竞争者评价

审查日期：2026-10-12。对象、截止日、八维权重及 9,031 个冻结功能区范围沿用[当地居民口径](cci-local-2026-scoring-calibration.md)。本轮把已知的条件性判断与未评估竞争者放入同一次算术演算，执行十组情景；**不是新的城市排名、完整八维评分或实际入围概率**。

输入逐行使用冻结全候选 CSV、当前统一矩阵和矩阵登记的全部六份审阅：五份完整条件性中心、一份部分维度案例。不按旧名单、人口、国别、资料量或提名筛选。案例 JSON、证据文档、候选清单、矩阵及脚本均有哈希对账。只从不可变生产发布读取八维权重，不读取旧城市得分、事件或研究半宽。

## 已实跑的结果

先暂时固定五城的条件性中心及加沙四项条件判断；加沙其余维度及其他 9,025 城仍未知。`fixed_conditional_centers` 为既有情景键名，部分案例不会因此获得总分中心：

| 案例       | 固定条件中心 | 算术位置最前／最后 | 判读                                               |
| ---------- | ------------ | ------------------ | -------------------------------------------------- |
| 新加坡     | 58           | 3—9,031            | 不能证明入围；同分次序未设定                       |
| 伦敦       | 58           | 3—9,031            | 不能证明入围；不能只与新加坡比较                   |
| 赫尔辛基   | 60           | 1—9,027            | 不能证明入围；比少数案例高不解决未知竞争者         |
| 苏黎世     | 58           | 3—9,031            | 不能证明入围；仍依赖全部必要假设                   |
| 加沙功能区 | 无；域 14—59 | 3—9,031            | 四维未定；不能将部分低档升级为全城排除             |
| 东京功能区 | 60           | 1—9,027            | GSS 实际影响及其他维度仍有时间、边界与居民触达假设 |

这些范围允许未知分数在模型域内变化、同分占据任意位置；不是假定所有极端情景现实中同样可能，也未检验跨城联合情景的概率或物理一致性。固定中心更不是可靠城市上下界，不能用这种情景的排除结果作为实际停止调查的依据。

随后对全部案例同时将 PCS、GSS、ISR、RES、MED、LON、TEC、OPT 分别改为未知，共八组；其他给定判断暂时固定。所有案例均无总分中心，算术位置均为 1—9,031。例如 MED 未定时，三个原 58 案例的给定条件总分域为 49—64，赫尔辛基及东京均为 51—66，加沙为 11—71；LON 未定时五个完整案例均为 54—64，加沙原本就未定，不额外改变 14—59。东京 GSS 假设撤回为 51—66、无中心，RES 或 OPT 假设撤回为 54—64、无中心，其他判断不随之重新归一化；已见交通和资金路径也不成为默认迁居许可。这不仅是 LON 一项敏感：其他必要假设失去依据也不能自动保留原分。

最后撤回全部八维必要假设；所有候选均无中心，保留完整模型域 0—100、算术位置 1—9,031。**0 与 100 是数学域端点，不是给未知城市打分，也不是研究测得的上下界。** 十组演算中，均有 9,031 个候选未被其给定范围排除。没有合格第 32 名门槛，实际有依据的排除仍为零。

## 统一计算规则

维度分数只来自已登记且带依据与必要假设的案例判断；局部地震、网速、国家背景等不自动转成全维分数。没有给定判断的维度保留未知，不填 0、50 或 60，不把已知维度权重重新归一化。

- 给定部分的加权贡献为 `L = Σ(已给定维度分数 × 原权重 / 100)`。
- 未知维度权重合计为 `M`；其数学域贡献为 `0—M`，故总分域为 `L—(L + M)`。只有 `M = 0` 才有给定条件下的中心。
- 对候选 i，其最前位置为 `1 + 其他候选中下端点严格高于 i 上端点的数量`。
- 最后位置为 `候选总数 − 其他候选中上端点严格低于 i 下端点的数量`。

严格比较保留同分的不确定次序，不以 CSV 顺序破同分。它描述给定域内的排序可能性；研究假设下的域不自动变成实际可靠排除界限。只有确立合格的证据界限与第 32 名门槛，才可能支持停止深入调查。

较新 UCDB／WUP 未匹配中心仍属于全球目标的待核验竞争者，不包含在上述旧功能区计数中，也没有被排除。这些数值只能说明当前声明范围仍不可判定，不能用来证明当前全球覆盖完整。

**范围资格检查已接入：** [全部 4,141 条未匹配记录](cci-unmatched-centre-review.md)保留八维未定、空总分及来源 ID；跨来源相交图的 2,432 个组只用于边界复核，不合并城市身份。50 组间接 FUA 联系也不证明实际居民覆盖，不能继承分数或获得排除。运行名次审查前重新计算完整登记、核对 CSV 与清单及矩阵引用，汇总保存 `outsideFrameReview` 和 `globalRankingEligible = false`。旧范围的算术位置不变，不将记录数或组数添加到公式冒充独立竞争城市；全球资格仍不成立。

## 复算、输出与验证

[全量逐行 CSV](data/cci-local-2026-rank-audit.csv)保存每个候选的给定条件中心／数学域、算术位置及撤回全部假设后的状态；[汇总 JSON](data/cci-local-2026-rank-audit.json)保存十组情景、案例结果、未排除数量、来源与脚本哈希。字段中的 `conditional` 指暂时接受案例必要假设，不授予排名资格。

```sh
pnpm exec python3 -B scripts/cci_local_rank_audit.py
pnpm exec python3 -B scripts/cci_local_rank_audit.py --check
pnpm exec python3 -B -m unittest discover -s scripts -p test_cci_local_rank_audit.py
```

标准库实现复用既有候选连接及案例协议验证。测试覆盖未知竞争者推翻样本名次、第 32 名同分、严格界限与等值界限的区别、部分低档仍与 58 重叠、未定不填零／中点／不重新分配权重，以及非法数值拒绝。案例协议拒绝部分案例声称有总分中心。`pnpm cci:check` 另核对生成产物的输入、文档、脚本与 CSV 哈希，并直接比较生产维度权重；不要求 Node 构建环境安装 Python。

下一项应扩大真正有依据的八维评价，优先解决能收窄候选域或改变入围结论的未知项，并检验真实高低档锚点和必要假设；不是把这十组演算当作已经完成全量评分。六份审阅没有优先入围名额；部分案例不增加完整总分数量。
