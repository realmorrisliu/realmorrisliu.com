## 统一计算规则

维度分数只来自已登记且带依据与必要假设的案例判断；局部地震、网速、国家背景等不自动转成全维分数。没有给定判断的维度保留未知，不填 0、50 或 60，不把已知维度权重重新归一化。

- 给定部分的加权贡献为 `L = Σ(已给定维度分数 × 原权重 / 100)`。
- 未知维度权重合计为 `M`；其数学域贡献为 `0—M`，故总分域为 `L—(L + M)`。只有 `M = 0` 才有给定条件下的中心。
- 对候选 i，其最前位置为 `1 + 其他候选中下端点严格高于 i 上端点的数量`。
- 最后位置为 `候选总数 − 其他候选中上端点严格低于 i 下端点的数量`。

严格比较保留同分的不确定次序，不以 CSV 顺序破同分。它描述给定域内的排序可能性；研究假设下的域不自动变成实际可靠排除界限。只有确立合格的证据界限与第 32 名门槛，才可能支持停止深入调查。

较新 UCDB／WUP 未匹配中心仍属于全球目标的待核验竞争者，不包含在上述旧功能区计数中，也没有被排除。这些数值只能说明当前声明范围仍不可判定，不能用来证明当前全球覆盖完整。

**范围资格检查已接入：** [全部 4,141 条未匹配记录](cci-unmatched-centre-review.md)保留八维未定、空总分及来源 ID；跨来源相交图的 2,432 个组只用于边界复核，不合并城市身份。50 组间接 FUA 联系也不证明实际居民覆盖，不能继承分数或获得排除。运行名次审查前重新计算完整登记、核对 CSV 与清单及矩阵引用，汇总保存 `outsideFrameReview` 和 `globalRankingEligible = false`。旧范围的算术位置不变，不将记录数或组数添加到公式冒充独立竞争城市；全球资格仍不成立。

```sh
pnpm exec python3 -B scripts/cci_local_rank_audit.py
pnpm exec python3 -B scripts/cci_local_rank_audit.py --check
pnpm exec python3 -B -m unittest discover -s scripts -p test_cci_local_rank_audit.py
```
