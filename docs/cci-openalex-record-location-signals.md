# OpenAlex 全候选目录关联记录信号

核验日期：2026-10-12。数据仍冻结为 **2026-09-23 快照、`publication_year=2025`**，CCI 证据截止日仍为 2026-10-10。本说明允许将已有完整投影按目录功能区汇总为研究线索；它不提供真实科研产出、TEC 分数或候选排除依据。

## 可以计算的量

对每条声明作者名单已对账的作品，沿用 [既有判读函数](../scripts/cci_openalex_affiliation_audit.py) 的全部条件：署名直接机构 ID 为原始单位匹配 ID 与展开机构 ID 的并集；仅当全部直接机构具有唯一目录 FUA、它们共同指向一个 FUA，且八种歧义标记全部为假时，该署名才合格。八种标记是无匹配机构、原始／展开 ID 不一致、原始单位未匹配、无单位记录、机构不在冻结目录、机构无唯一目录 FUA、多个目录 FUA、直接父子机构重叠。**不能因为父子机构恰好在同一城、展开 ID 看似可信或部分单位已匹配而放宽规则。**

每条作品先取合格署名所指向的 FUA 集合；每个 FUA 对这条作品最多记一次“至少一条署名具有单一且一致目录 FUA 的记录存在”。同城多作者不重复，不同城合作者各城可以出现一次。因此全城计数之和是作品—FUA 关联数，不能叫全球唯一作品数、合作贡献或分数计数。未知署名不分给已知城市；空名单不合格。全部作者各自合格仍允许不同城市，也不能说整篇只属于一个城市。

这一口径是对源字段的保守记录关联，不是无误差的科研量下界：[OpenAlex 作者单位](https://help.openalex.org/data/authorships/)来自源署名文本解析及机构消歧；[机构目录](https://help.openalex.org/data/institutions/)的位置和谱系描述组织，并不能保证实际研究校园、实验室或活动地点。误匹配和总部／多校区问题仍可能产生错误关联；没有列出所有实际单位也可能漏掉关联。最新机构文档所述 2026-09-28 匹配器 v3.0 及其基准不能转用于早于部署的本批快照。

## 类型、语料及撤稿必须分开保留

按冻结记录的 `(type, is_xpac, is_retracted)` 分层保留计数，包括未知值，不将未知布尔标识改为假。每条作品的类型只取源记录一个值，不用当前在线标签重写旧快照。[官方类型定义](https://help.openalex.org/data/work-types/)区分以下含义：

| 字段／类型                              | 在本批信号中的含义                                                                                                                              |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `article`、`conference-paper`、`review` | 不同出版形式分别计数，未做质量、领域、规模或影响归一化。                                                                                        |
| `dataset`                               | 数据制品记录，区别于描述数据的 `data-paper`；不与论文按条数等价相加。                                                                           |
| `preprint`                              | 以预印本库为主要位置的作品记录；不自动视为未重复的独立成果。                                                                                    |
| `retraction`                            | 撤回另一作品的通知这一类型，区别于一条作品本身的撤稿状态。                                                                                      |
| `is_retracted`                          | [已知撤稿标记](https://help.openalex.org/data/works/attributes/)；假不证明从未撤稿，未知保持未知。                                              |
| `is_xpac`                               | [扩展语料标记](https://help.openalex.org/data/works/corpus/)；语料来源层而非类型或质量等级。core 仍含 dataset，扩展层也不能一概当作无科学价值。 |

完整、逐类型及 core／扩展对照用于识别大数据存储、类型混合及元数据覆盖造成的排序变化。若另外展示明确的非撤稿 article 等子集，必须显示精确筛选条件，仍称该子集的目录关联记录量；其他记录继续保留在完整对账中。选择子集本身不能成为低分或排除城市的理由。

## 日期与去重能证明到哪里

[快照说明](https://help.openalex.org/access/snapshot/)明确快照是时点数据，包含扩展语料，实时 API 持续变化且默认 core。不能拿当前 API 或较晚机构匹配替换本批行，再用旧快照哈希声明一致。发表年份是作品出版年份，[作品日期说明](https://help.openalex.org/data/works/attributes/)允许不同版本日期不同；2025 年记录是 2026 评价的既往线索，不是 2026 年产出实测。2026-10-12 的本地验收／文档核查不改变底表日期或证据截止日。

[完整筛选审计](data/cci-openalex-filter-inventory.json)已经验证 45,069,447 条 2025 年记录及同数唯一 OpenAlex ID。该唯一性只解决此冻结集合的记录重复：[OpenAlex 作品合并](https://help.openalex.org/data/works/)使用共享标识符和模糊元数据匹配，未匹配副本会产生另一记录；[后续合并／删除](https://help.openalex.org/access/sync/)也会改变较新集合。因此不能声称独立知识成果、预印本与正式版、数据制品版本均已去重。不要在没有逐条版本证据时自行删除类型或相似题名。

## 全量对账与候选保留

[正式全量地理诊断](data/cci-openalex-global-affiliation-audit.json)已经逐分区连接、核验 45,069,447 条记录和 154,673,582 条署名，其中 114,495,829 条署名合格，26,684,579 条作品至少有一条合格署名，23,934,309 条的全部署名合格；934,310 条零作者记录保留未分配。这些是已核验输入统计，区别于逐 FUA 关联数。歧义标记重叠，不可相加作为失配总数。

汇总应复用 [全量诊断入口](../scripts/cci_openalex_global_affiliation_audit.py) 的完整清单、源元数据、机构目录、脚本版本、Parquet 哈希、行数和逐值连接校验；不得只扫完成目录或未核验缓存。全库类型／语料／撤稿分层与冻结筛选审计一致；至少一条合格署名的唯一记录总数必须对账既有诊断，同城去重后各 FUA 分层之和只对账作品—FUA 关联数。

输出保留全部 **9,031** 个冻结候选，不按计数截取前列。零意味着“本冻结集合及此严格规则未观察到合格目录关联记录”，不能推断零研究产出；正数也不能推断居民受益、数字服务普及或 TEC 达标。该信号可以决定核查哪些记录、机构地点、类型和版本差异，但不能直接生成 CCI 名次、缩小候选资格或证明未匹配城市无法入围。较新城市覆盖缺口仍另行保留。

## 输出与复算

[逐候选关联表](data/cci-openalex-efua-record-presence.csv)每个冻结候选一行；`record_presence` 只表示跨类型的元数据记录关联总数，不能用作成果或能力排序。各分层列采用 `type__xpac_<true/false/none>__retracted_<true/false/none>`，`none` 明确保留源 JSON 的 `null`，不并入假。类型包含全部冻结来源值。

[汇总与哈希](data/cci-openalex-efua-record-presence.json)保存候选、目录、完整作者清单、筛选审计、判读与执行脚本、诊断及 CSV 哈希；来源分层的 `count` 是全库记录数，不是该层的逐区关联总和。入口同时输出诊断与关联表，矩阵按哈希、候选集合及总数拒绝陈旧或不完整输入。

```sh
pnpm exec /private/tmp/cci-global/geo-venv/bin/python -B scripts/cci_openalex_global_affiliation_audit.py \
  --cache /private/tmp/cci-global/openalex-2025-authorships \
  --filters /private/tmp/cci-global/openalex-2025-filters \
  --output docs/data/cci-openalex-global-affiliation-audit.json
```
