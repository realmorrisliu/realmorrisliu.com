# CCI 医疗可达性：全候选人口加权核查

核验日期：2026-10-10。已对全部 **9,031 个冻结 eFUA** 计算同一口径的结果，没有按旧榜单或数据完整性排除候选。结果是 **2025 年投影人口下的 2019 年医疗旅行时间模型**，不是 2026 年医疗实测或 MED 总分。

## 输入与网格对齐

人口采用 JRC [GHS-WUP-POP R2025A](https://data.jrc.ec.europa.eu/dataset/adba95af-db56-4569-acd3-9513201eba30) 的 2025 层，单位为每像元投影人口；2025 层由模型推演，不是人口普查。[官方许可](https://jeodpp.jrc.ec.europa.eu/ftp/jrc-opendata/GHSL/GHS_WUP_POP_GLOBE_R2025A/copyright.txt)为 CC BY 4.0。下载及完整解压已完成；[输入清单](data/cci-healthcare-population-source.json)保存 ZIP/TIFF 哈希、地址和实际元数据。未使用前一步下载的旧版 R2023A 人口文件。

两来源都标称 30 角秒，但实际网格不同：医疗图分辨率为 `0.008333333333333333°`、原点 `(-180, 85)`；人口图为 `0.0083333°`、原点 `(-180.0079, 89.09958)`，尺寸为 43,202 × 21,384，Float64，NoData 为 `-200`。不能直接按数组下标相乘。

计算保留人口原网格及原值，在人口像元中心读取最近的医疗栅格值（GDAL WarpedVRT / nearest）。只采样旅行时间，不重采样人口数量。按已细分至 1,000 米的 eFUA 边界选择中心位于其中的整像元人口。这是约 1 km 网格的离散近似，不是边缘像元精确人口分配；小岛、细窄地带与海岸城市仍需边界敏感性检查。

## 均值与缺失情形界限

每种交通模式分别保存有旅行时间、缺失旅行时间及有记录且在 60 分钟内的人口。分母是所选像元中具有有效人口值的总量；人口本身缺失的像元另计数量，不假设无人居住。

- 平均分钟数只在有旅行时间记录的人口中计算，列名为 `mean_minutes_among_observed`；无有效人口时留空。
- 60 分钟比例下界 = 已观察到 60 分钟内的人口 / 已知选中人口。
- 上界 =（上述人口 + 旅行时间缺失人口）/ 已知选中人口。

这是固定模型与已知人口分母下，对缺失旅行时间作极端假设的界限，**不是统计置信区间或实际居民医疗可达性的保证界限**。它不包含设施漏报、速度模型、边缘像元、人口误差、费用或就医资格等不确定性。60 分钟是原研究使用的可解释阈值，不是 CCI 评分锚点。

## 验证与复算

23 项离线测试通过，包含异原点网格的真实 GeoTIFF / VRT 测试、NoData 不当零、人口分母为零时不产生比例、缺失情形界限及人口加权均值。另逐行核验 9,031 个唯一候选、每模式的已观察人口加缺失人口等于分母，以及 0 ≤ 比例下界 ≤ 上界 ≤ 1（允许浮点误差）。
