# 杭州功能区：八维完整条件评分58

证据截止 **2026-10-10**，实际复核 **2026-10-13**。对象为本国公民、通常长期居住、当地中位收入与通常医保的普通居民。冻结候选 **eFUA10078／Hangzhou**，沿用[共同锚点](cci-global-scoring-rubric.md)和原八维权重。

**PCS／GSS／ISR／RES／MED各60，LON／OPT各40，TEC80；条件性总分58。** 八维及31子支柱均已审阅，不等于充分测量。完整表示已有八个可撤回判断，不表示全球名次、确定优劣或入围资格。

## 长寿40与未知的分界

支付窄核单独建议未知，因为正式商保责任及完整监护费用尚未闭合；最终合并判读接受**条件40**。理由是已有实际给药、当前适合者因费放弃与正式基本支付边界，不是缺少商业合同本身。

[2026-07-29原记者调查](https://zjnews.zjol.com.cn/wyly/202607/t20260729_31814595.shtml)记录树兰（杭州）两个月余实际4人用药，也记录适合者因费用放弃；市一城北和树兰等院内药路径提供替代。采访不是院方账册，未确认实际输注院区，不能把外地咨询者全部视作目标居民，也不将新闻中的商业赔付比例当已核合同。

[国家2026执行目录通知](https://www.nhsa.gov.cn/art/2025/12/7/art_53_18971.html)明确商保创新药目录的药品不由基本医保基金支付；推荐商保参考不证明某保单已经覆盖。[杭州正式办法](https://zfgb.hangzhou.gov.cn/upload/default/bigfile/2025/10/15/20251015_ec3d3e35772bc2a066570411d334c03f.pdf)条46的AD门特需定点证明及备案，目录内项目按住院规则无起付；不能推成两种单抗或全部检查／输注／监护均获支付。条47列入慢病也不等所有基层AD治疗自动免起付。

40须接受实际给药地点属于本区、7月状态延续至截止、受访适合者费用放弃对通常基本险／中位收入画像有代表性，以及已有缓解后障碍仍重要。**拒绝任一必要假设，LON恢复未知，总分中心撤回，数学域54—64。** 若当前实际支付／帮助与监护路径足以使通常合资格者可承担，60可成立；不要求完美个人账单，不默认已投保自愿商保。两种疾病限定治疗不代表健康人延寿。

## 核验后保留的范围与数字限制

- **地界：** 原几何全库9,031条及SHA已核。萧山／笕桥机场目录点属10078；嘉兴南湖点属10118，建德两点旧全库无匹配。目录点不是设施足迹、独立客运备援或居民覆盖；市级统计、大学平台、医院品牌及外地厂场仍须有限适用推定。
- **水与供电：** 2025龙头15份样本、每份38项，共570项次，不是570户；2026管网表是月均，不证明每份合格。总氯与另一表适用脚注的差异保留。施工预计复水不是已复水；6.01分钟为2024户均停电，不是2026全区实测。
- **医疗：** 2026发表的手术室研究观察2024；347设备、156员工、28手术室不是患者数。安全事件为每千操作3.2至1.8，非百分比或全区风险调整结局。231透析受访者混合浙江／新疆，不全为本区。急救个案9天转出监护不等出院或通常治愈率。
- **技术与退出：** 滨江平台正文2025-11-29与网址2026-01-26分开；二手房掌办为251件，非251万。多项办件可能重叠，不能算独立居民。机场暑运稿台风名称与时间窗未闭，不作2026压力运行证明；GFW原实验没有杭州点。

上述限制不自动降分；有依据的残余障碍重要性和实际缓解共同决定档位。所有空间、通常居民、延续、资格／负担及残余重要性推定都可撤回，不要求新城市达到比既有城市更强的完美测量门槛。

## 复算与研究进度

原权重总分：`60×15%×4 + 60×10% + 40×10% + 80×10% + 40×10% = 58`。前四个15%为PCS、GSS、ISR、MED，60的10%为RES。

- TEC改60，总分56；LON或OPT改60，总分60；MED或ISR改40，总分55。替代情景须有相应实质解释，不是自由填分。
- 撤回任一60分／15%维度，域49—64；撤回RES，52—62；撤回LON或OPT，54—64；撤回TEC，50—60。均无总分中心，数学端点不是可靠城市上下界。
- 本批新增杭州并完成大阪—京都／南京补审后为26份审阅、12份完整／14份部分，9,005个冻结候选尚无此类八维审阅；较新竞争者也未排除。零有依据排除，无合格第32名门槛。
