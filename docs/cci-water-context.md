# CCI 城市饮用水服务：国家城市人口背景

核验日期：2026-10-10。来源为 WHO／UNICEF JMP，经世界银行 WDI API 获取；统一采用 2024 年估计，不把 API 的 2026-10-08 更新日期当成观测年份。指标元数据注明 JMP 发布于 2025-08-25。来源 URL、原始响应哈希和 CC BY 4.0 许可位置见[来源清单](data/cci-water-source.json)。

## 两项指标不能相加或互相填补

- `SH.H2O.SMDW.UR.ZS`：国家城市人口中使用安全管理饮用水服务的比例。需要改良水源位于住所范围内、需要时可用，并符合相应污染物要求。
- `SH.H2O.BASW.UR.ZS`：国家城市人口中使用至少基本饮用水服务的比例，包含上述安全管理服务。基本条件涉及改良水源及往返取水时间，不能单凭此项证明水质或持续可用。

定义依据 [JMP 饮用水服务阶梯](https://washdata.org/topics/drinking-water)及 API 原始元数据。二者不是独立得分项；安全管理缺失时不以基本服务替代，也不记零。100% 是来源估计，不代表灾害下永不中断。

## 实际采集与候选关联

API 返回 532 条地区—指标记录，核验分页已完整取得。使用官方国家元数据排除区域、收入组等聚合；其中 10 条收入组记录的 ISO3 为空，通过官方 ISO2 元数据确认其聚合身份后排除，不当作国家或空国家行。保留 **217 个国家／地区、434 条指标记录**，包括显式缺失值。安全管理指标有值的国家／地区为 **102 个**，至少基本为 **178 个**；共同有值时，安全管理比例均不高于至少基本比例。

所有 9,031 个 eFUA 按国家代码引用背景记录：

| 1              | 1,556    |

采用此前已核验的 Kosovo `XKO → XKX` 别名；其他代码精确匹配，不把属地或未匹配司法辖区自动归入母国。国家估计只保存一份，功能区表保存引用，不复制成城市实测值。该来源的 urban 定义也不必等同于冻结 eFUA 的人口范围。

- [国家城市人口估计](data/cci-water-2024-country-urban.csv)：原始百分比与缺失状态。
- [全候选背景引用](data/cci-water-efua-context.csv)：保留全部候选和无资料状态。
- [计算及输出清单](data/cci-water-context.json)：输入、代码、结果哈希与计数。

该证据支持 `RES.water` 的背景判读，但不能区分同国城市、推定当地中位收入居民的负担能力，或补齐库存、备援水源、干旱应对和灾后连续性。它也不覆盖食物、能源或供应链。两种居民视角可以引用同一来源，但实际可得条件仍须各自解释。

## 复算与验证

原始 API 响应保存在 `/private/tmp/cci-global/`，正式复算按来源清单重新获取并核验哈希；失败的批量元数据响应未纳入，两个指标定义分别获取。生成器拒绝缺页、重复记录、未知代码及非有限或越界百分比；空值和数值零严格区分。

```sh
pnpm exec python3 -B scripts/cci_water_context.py --source-dir /private/tmp/cci-global
pnpm exec python3 -B scripts/cci_global_evidence_matrix.py
```

已验证全部候选引用、两项指标的包含关系以及聚合排除；测试覆盖缺失不填零、零值仍可引用、重复拒绝和不完整分页拒绝。当前未生成 RES 或总分，未改动历史发布。
