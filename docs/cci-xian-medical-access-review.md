# 西安普通居民医保、支付与接诊连接复核

证据截止 **2026-10-10**，实际取回／核读 **2026-10-13**。本国公民、通常长期居住、当地中位收入与通常医保；eFUA7094不等全部行政西安，所有院区和患者来源不由名单自动定位。

**普通参保、政策支付与实际医保定点路径已补强；与临床合并后采纳MED可撤回的条件性60。** 定点协议不证明所有合资格者及时入院，医院流程不等已结算每名患者；合并[临床复核](cci-xian-medical-quality-review.md)后，常规感染改善与真实专科能力成立，但当前全区压力备用、完整疗程负担及质量分布仍未充分测量。以真实路径及明确通常获得／负担／延续推定评分，不以资料少、缺完美中位私人账单或缺当前实战作为西安独有的未定门槛。

## 当年资格与保障窗

[税务／医保联合参保通告](https://cbip.xa.gov.cn/xwzx/tzgg/1981608632276049922.html)署名2025-10-20、刊于10月21日；官方题名为2025参保缴费，选择缴费年度2026，不能仅因题名变成2025保障。户籍或取得本市居住证、未参加职工险者可参加居民险；个人400元、财政700元、合计1100元，并列困难身份资助。正常集中缴费2025年10月至12月25日且连续者保障2026-01-01—12-31；不连续的普通集中缴费者固定等待3月、保障4月1日起；期外依长效机制，等待期间费用不报销。新生儿／学生有专门例外，不套到普通成年居民。

[2026等待问答](https://ybj.xa.gov.cn/jlhd/hygq/jmyb/2021413264091619329.html)2月10回复、11日刊，继续明确集中期外／非连续者的3月固定等待及新生儿等例外。它没有给本区未参保率、净支出或获益人数。400是保费，不是全年所有治疗自付；资料没有证明画像居民人人参保，但明确假设通常居民已在应享期、选择适合其就业资格的基本险。

线上与银行／税务柜面多途径真实公布，新增人员需身份及户籍／居住证登记；职工险和居民险不能默认同时报销。办理入口与制度存在不是每笔已经成功、未延迟或可在病后追溯。

## 实际2026协议与必要接诊连接

[市经办中心2026年第6号公告](https://ybj.xa.gov.cn/szyw/tzgg/2094288094537768961.html)署名8月28日、刊8月31日，明确附件列**2026已签医保协议**，不只是计划招募。[180页原PDF](https://ybj.xa.gov.cn/web_files/ybj/file/2026/08/31/202608311138478396516.pdf)第一页面目视核：一附院H61011400908（含东／南／陆港），二附院H61010200914（含大明宫），省人民H61010301352（含西咸），高新H61011300660，均列门诊、住院。文本定位西航H61011200486／凤城H61011200456亦列门诊、住院。医保代码不是每个物理院区单独编号，不重复算多提供者或独立备援。

省人民同条同时列友谊西路256与西咸秦汉新城地址，后者参考点7004；第一方2024输注正文未写院区，不能因当年契约或主院地址确定历史每例治疗地。临床研究机构真实但患者居民身份、转院排除和实际治疗院区仍按临床复核限制。名单证明本期正式可走医保服务的机构通路，不证明全区覆盖、每项药／检查获赔、所有合资格者能立即获得治疗。

## 本地提供者结算表与普通负担

[西航医保办2025-11-10住院指引](https://xhyy.umcare.cn/c/2025-11-10/739014.shtml)要求住院证、入院缴费、医保凭证与身份证到医保办审核。居民表：三级特等2000／50%，三级1200／60%，二级400／70%，一级150／80%。这是起付以上适用统筹费用口径，**不是整张账单同百分比**；目录外、先行自付、共付、上限、垫付与连续疗程均可能改变普通负担。

职工三级前三次住院650／550／350元，第四次及以后不设起付。其费用分档表原HTML明确最后一个“95%”单元格 `rowspan="6"`，跨在职／退休六行：在职三级起付以上至1万元88%、1万至5万元91%、5万至最高限额95%；退休三级91／94／95。不能把抽取文字缺第三格当真实无比例，也不能把跨行结构擅自修改为其他档位。三级特等起付850／800／550与普通三级分列，不从另一城市86%或800元移植西安。指引发布日期2025，2026协议及问答提供延续线索，实际现行细项无截止字节归档；接受制度／通常应用延续仍是可撤回推定。

[2026慢特病办理回复](https://ybj.xa.gov.cn/jlhd/hygq/mzmtb/2094970815110492161.html)要求参保、当地目录及鉴定，提交病历／检查至指定机构后审核、生效后定点结算。各地标准不同，不能把全省一般步骤当西安全部病种额、等待或每药当前覆盖。[2026一般保障回复](https://ybj.xa.gov.cn/jlhd/hygq/jmyb/2021412734231474177.html)及已目视附图仅列六种保障，不是具体支付表。[大病回复](https://ybj.xa.gov.cn/jlhd/hygq/jmyb/2021422186997846018.html)标来源福建，不能拿其图或其它省比例补西安档位。

[2023生育调整原文](https://ybj.xa.gov.cn/szyw/ybdt/xaybdt/64c85ef3f8fd1c1a7035ebdf.html)有女职工产检2500一次补贴、居民三级分娩600／特等1000、二级以下政策范围支付等实际规则；先垫及用人单位后转付分列。旧规则的延续须明示，不能把2026全国“无自付”例举或武汉新政策套入西安，不推所有合并症／目录外费用免费。

## 合并判档与撤回

支付通路支持MED access的partial，不自动支持80或60。2026发表院感观察截至5月有真实改善；精选样本、纳排图文不一致与过程分母未知不是现实不当护理率。旧卒中排除4例操作相关并发症应保留，不能用零死亡证明全安全；2022分诊责任事故与实际三例替代分娩都不自动延续为2026全区压力结果。2025演练是已做演练，不能当实际风雨恢复。

共同60可以由已证明实际路径合并有依据的通常获得、适当治疗、延续和剩余重要性推定支持，不增“必须完美账单”的门槛。本轮核对东京及武汉同层级后采纳条件性60：接受核心提供者对7094通常居民必要护理具有合理代表性，已见管理／治疗与区域替代延续；合资格居民在应享期通常可接诊或必要转诊，承担适当连续治疗，既有共付／目录外／垫付并未形成重要持续阻断；历史失效和所见临床风险仍是强冗余判断的短板，不外推为2026普遍拒诊或全部不当护理。原院感图文和过程分母疑点不假定无害、也不直接作伤害率，必须保留。有当前重要未缓解必要护理／通常净负担障碍可40；较广当前实际质量和可承担压力备用可80。拒绝资格／地点／延续／代表性／通常负担及剩余影响推定则MED撤回null、总分中心为空，不把缺口当负分。下一项应核真实当前必要急危重转运／压力运行和通常连续治疗承担，或辨明原院感适用分母，避免再搜泛泛排名及无限病种。
