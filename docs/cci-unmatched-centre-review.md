# 旧 FUA 范围之外的竞争者：逐条保留，不能靠间接相交排除

审查日期：2026-10-12。复用已经冻结、验哈希的 UCDB R2024A V1.2、WUP R2025A V1.1（2025 年中心）及其完整空间连接；没有改变原八维、权重或旧候选边界。

此前名次演算完整覆盖旧 9,031 个 FUA，但较新中心只在说明中保留。现在将所有与旧 FUA 无直接正面积交集的中心逐条登记，接入统一矩阵与入围审查的范围资格检查。**这补上可审计的待核验竞争者记录，不解决城市身份或全球评分。**

## 全量连接结果

| 项目                         | 实查数量 | 含义                                                           |
| ---------------------------- | -------: | -------------------------------------------------------------- |
| UCDB 无直接 FUA 交集记录     |    1,861 | 全部保留，来源 ID 不与 WUP ID 混用                             |
| WUP 2025 无直接 FUA 交集记录 |    2,280 | 全部保留，仍是城市中心而非通勤区                               |
| 两来源记录合计               |    4,141 | 是记录数，不是新增或去重城市数                                 |
| 跨来源相交图的连通复核组     |    2,432 | 仅用于一起核查边界，不合并城市实体                             |
| 有间接旧 FUA 联系的复核组    |       50 | 某个成员与另一来源的已相交中心有联系；不证明居民覆盖或同一城市 |
| 无这种间接联系的复核组       |    2,382 | 仍待核验，不证明新建城市或低能力                               |

只使用已核验的正面积交集边。相同整数 ID 分别加来源命名空间；不按名称、人口、国别或资料多少过滤。未匹配记录之间的连通分量形成复核组，源记录不删、不折叠，保留逐条内部联系及通向另一来源已与 FUA 相交中心的联系。

**图连通不证明城市身份相同。** A 与 B 相交、B 与旧 FUA 相交，不能推出 A 居民已经在旧 FUA 内，也不能将 B 的分数、医院可及性或科研成果转给 A。链式相交也可能涉及不同中心或边界版本；50 组间接联系全部保留未定，不获得排除资格。其余 2,382 组也不能自动成为新增的 2,382 座城市。

所有 4,141 条记录保留八维 `not_assessed_under_global_protocol`、空总分及 `retained_unresolved_competitor` 状态，没有填写 0、50 或沿用相交对象分数。旧 9,031 个 FUA 继续单独保留，不能将两种统计单位拼成一个排名总数。

## 对入围审查的影响

[逐条 CSV](data/cci-unmatched-centre-review.csv)保存来源 ID、复核组、两种联系、八维及总分状态；[汇总与溯源](data/cci-unmatched-centre-review.json)保存输入清单、来源版本、文件及脚本哈希。统一矩阵登记其记录数、组数及校验和；名次审查在运行前重新计算并核对完整登记，页面构建与 CCI 检查另核对引用一致性。

当前 `globalRankingEligible = false`。旧范围的名次域仍只针对 9,031 个 FUA，不将 4,141 条记录或 2,432 个组数加入名次公式冒充独立城市；即使将来旧范围内第 32 名稳定，也不能绕过这些未解决竞争者后声称全球前 32。

接下来需要对这些复核组确定统一地理单位及身份映射，并从实际居民覆盖与八维证据判断是否是独立竞争者、已有候选的边界更新或应整体迁移的单位。这个登记也不覆盖来源定义以下的所有聚落，不解决已有相交中心的部分覆盖、多对多映射或实际通勤联系。相应原始记录仍保存在[空间核查](cci-global-spatial-audit.md)和[WUP 核查](cci-wup-2025-crosswalk.md)中。
