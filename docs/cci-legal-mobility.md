# 当地居民 OPT：可共用的附条件法律路径

**2026-10-12 印尼法律条件扩展：** 核读同一德国原法与驻雅加达使馆2026-06-29国家签证原说明，向全部 **249 个 IDN 功能区**关联限定工作目的的入境前路径。当前 **2,838 个**候选有已审法律条件，**6,193 个**待审；国籍、资格、费用和最终批准均不默认成立。不改变原十九份评分或零排除；以下2,589及更早计数为阶段快照。

**2026-10-12 全候选扩展：** 新核既有德国原法 §6(3)、§18／18b 的通常入境前国家签证与合资格工作居留路径，关联全部 **1,539 个 CHN 功能区**。当前 **2,589 个**有已审查法律条件、**6,442 个**仍未审；十八份案例档位、总分及入围演算不改变，以下 1,050／7,981 为此前快照。中国公民不继承 §41(1) 的境内申请便利；存在适用法定条件不等于已经获签、就业、能够负担迁居或完成 OPT。

口径沿用 2026 年、本国公民、当地中位收入与通常医保；证据截止 2026-10-10，实际查阅 2026-10-12。[结构化规则](data/cci-legal-mobility-rules.json)仅支持 `legal_mobility` 的法律条件，不生成 OPT、CCI 或排除界限。

## 全候选应用与评分边界

统一矩阵保留全部 9,031 行。422 个其他欧盟成员国功能区关联德国，88 个德国／冰岛／挪威／瑞士功能区关联法国；列支敦士登在冻结库无候选。新增 §41(1) 程序条件关联澳大利亚 20、加拿大 35、英国 91、以色列 9、日本 88、韩国 30、新西兰 7、美国 260 个功能区，合计 **540 个新增、1,050 个已审查法律条件的功能区**。这不是 1,050 个已获长期居留权或已完成 OPT 评价的城市。其余 **7,981 个**记录 `no_reviewed_path_not_no_right`，不是无权迁移、低分或排除；先前 510／8,521 是扩展前快照。

ISO 代码只用于在既定“本国公民”画像下选择法律规则；居住地点本身不能证明国籍。海外地区不自动换成宗主国国籍，外国居民和国籍未定的跨国迁居者不得继承该关联。需要不同身份时重新核验，撤回国籍假设则本项恢复未知，不移动或给零任何分数。

这与国家治理代理不同：法律直接规定人物资格，可在同国候选之间共用；但是通道是否能让普通居民实际退出仍取决于就业、储蓄、医保、家庭、行政落实、交通、资产和通信。中位收入不等于足够迁居资源；没有独立替代目的地或危机有效性测量，不能支持 OPT 80，亦不能仅凭单一合法路径给 OPT 60。

矩阵保存法律状态、规则 ID、目的地；本轮只更新新增 540 行的这三个法律字段，原八维局部状态与七份案例分数逐行不变。华盛顿的法律子项从未定推进至部分审阅，资产及通信仍待查、OPT 无档位。规则、说明及生成器的哈希接入复算和网站质量检查。单元核验覆盖身份／截止日错配、目的地等于来源、重复国别规则、未知来源拒绝、属地不继承规则，以及有居留路径或申请程序也不授予分数、排除或入围资格。

下一步应把这项共用证据与候选的实际费用和压力可用性一并判读，再写八维成绩单；不能把法律覆盖数量算作全量评分进度。第 32 名与未评估竞争者仍未解决。

## 中国公民工作路径：先核法律，才向全部同画像候选共用

本轮核读与原有八国案例相同的完整 [AufenthG 原法](https://www.gesetze-im-internet.de/aufenthg_2004/BJNR195010004.html)，从 HTML 声明的 ISO-8859-1 解码，不修改原字节。原件 `/private/tmp/cci-global/exit-laws/aufenthg-full.html`，979,856 字节，SHA-256 `035c430b7411f9bd8bb547aa4d6e0c1ade1e52c89089ba55b553977cf5f831a6`；合并文本的 2026-07-21／22 版本区别及查阅晚于截止的限制保留。新增条文 §6(3) 正文明确长期居留通常需要入境前签发国家签证，依相关居留目的条件办理；不能从短期申根签证推工作权。已读 §41(1) 列表不含中国，这不排除个人另有的合法例外。

§18(2) 对工作要约、必要就业机关同意、职业许可、适用学历和双方真实就业意图设条件；§18(3) 与 §18b 提供合资格高学历工作者居留目的，§5 的身份／生活保障和 §2(3) 医保、§4a 的就业权限仍适用。超过 45 岁首次相应许可的法定工资／养老替代与例外保留，不从 2025 使馆材料的冲突数字或原籍中位收入计算 2026 资格，也没有查到普通居民的实际获签率。

规则 `chinese_citizen_skilled_work_national_visa_germany` 仅在明确“中国公民”画像下关联 CHN 的所有 1,539 个功能区；不只填北京和上海。香港、澳门、台湾及外国居民不因地理或宗主关系改为 CHN。它与欧盟附条件居留权和八国 §41 申请程序分别记录：都是实际法律条件，不能自动给相同 OPT 分数。普通居民是否满足资格、拥有工作和资源、可转移资产、保持通信，仍须当地和人物证据。

应用前后逐行对照全部 9,031 候选，仅 CHN 的三个法律关联字段改变；原八维局部证据、已给定案例分数、排除状态与十组演算位置不变。共享规则文件扩展后，引用它的旧案例只更新来源哈希；原条文版本和实际判断没有被新规则覆盖。新增自检核查 CHN 为入境前条件路径而非 §41 便利、属地不继承，以及法律关联不产生城市得分或排除。
