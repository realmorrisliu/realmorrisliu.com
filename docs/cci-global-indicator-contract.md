# CCI 全球指标语义契约：八维、31 个子支柱

审查日期：2026-10-10（Asia/Shanghai）。依据 `src/cci/model.ts` 的实际注册表、[全球资料覆盖研究](cci-global-data-coverage-research.md)，以及本地 UCDB v1.2 手册和提取字典。这里只确定字段可以回答什么，不设评分锚点，不修改发布，不把字段非空率称为 CCI 概念覆盖率。

权重保持 **PCS 15、GSS 15、ISR 15、RES 10、MED 15、LON 10、TEC 10、OPT 10**，合计 100。31 个子支柱均保留。缺测不能记零、均值填补或由其他维度代替；也不能把已测部分重新归一化成完整 CCI 总分。各类资料不是独立证据时不得重复计权。

## 状态与空间边界

- **局部代理**：核验的字段确实测量该子支柱的一部分，但不能宣布整个子支柱已测量，也尚未承诺所有候选都有合格值。
- **未测量**：当前已核验资料没有足以操作化该子支柱的城市测量。可以保留背景证据，但不计作该子支柱的观测覆盖。
- **完整测量**：本轮没有任何子支柱达到这个状态。

以下 UCDB 字段均以**城市中心 Urban Centre（UC）**为统计空间；它们不是 eFUA 的完整观测。`XXXX` 是字典时间占位符，不是承诺每个年份存在。把多个 UC 连接到一个 eFUA 后，仍缺 eFUA 中的其他人口及设施。原字段的区域平均、空间求和与设施计数也不能一律按 UC 人口平均。应保留 `sourceGeography`、`targetGeography`、`spatialCoverage`、观察期、计算方法、来源偏差和许可状态；这些是结果解释所需的记录字段，不要求新增一个框架。

## 字典与方法的即时隔离事项

本轮手册核查发现以下冲突；它们应在主任务的数值审查中形成显式异常记录，而非猜测修正：

1. `EX_010_SHP_XXXX` 的 `name` 写 100 年、`description` 写 10 年；`EX_100_SHP_XXXX` 反之。先不使用两者参与评分。可用相同 epoch 的人口暴露计数与 UC 总人口验算份额，随后与发布方原始模式/更正说明确认重现期；验算相符本身仍不是发布方语义确认。
2. `HZ_CON_FAT_XXXX` 的名称/单位写死亡人数，说明写 one-sided violence 事件，方法又写 point-based 数据的 zonal count。不能默认是死亡求和；核对底层 UCDP 字段及生成方法前隔离。
3. 字典 `SC_CON_DSF_XXXX` 同时对应 fixed 和 mobile 下载速度；不能凭出现顺序选择。核对实际列名、对应表和上游固定/移动层后才能绑定。
4. `CL_UTC_T32_XXXX` 名称是日数，方法提到像元阈值计数/分区平均。可以保留热应激代理语义，但入模前须确认数值单位和上游聚合，不能误作人口热暴露比例。
5. HZ 冲突/灾害字段方法使用含糊的相邻年累计描述，且不同来源年代不同；没有确认窗口前不得作年度发生率或最新安全状况。暴露字段的多个年份有可能只是人口层变化，不代表危险层随年份更新。
6. `SC_SEC_*` 多个变量由同一 Subnational HDI 区域叠加获得；UC 间相同值可能是共享上游空间单元，不应通过去重删除城市，也不应算作多份独立本地证据。HDI、寿命、教育和收入重复使用还会形成内容重复计权。

## 最小可行的下一步与完成条件

**下一件能完整交付的工作是“全球候选 × 已核验局部代理”的测量底表，而非 CCI 总榜。** 对主任务已经冻结的候选总体，逐字段保存原始值、原始 UC/来源地区、epoch、单位、上游来源与处理状态；保持 `measured / missing / not_applicable / ambiguous` 可区分。任何空间映射失败、来源窗口不明或上面冲突字段均不进入派生指标。此底表允许比较某一明确测量，不能自行改名为完整八维覆盖。

具体依赖按顺序是：

1. **先关闭字段冲突与空间问题**：落实重现期、死亡字段、fixed/mobile、热日数和事件窗口；明确 eFUA 的 UC 人口覆盖、边界跨期一致性及不可比城市清单。数值完整性报告与本语义契约分开保存，避免一个通过掩盖另一个失败。
2. **补能批量取得的实质缺口**：知识产出使用同版 OpenAlex/WIPO 作机构归属与合作分摊；组织暴力使用确认窗口/口径的原始事件；交通冗余需要真实路网和独立替代路径，不能只有长度。先验证字段能覆盖全候选，再决定是否使用；这几项补完仍不足以覆盖其他子支柱。
3. **对当前无法批量测量的概念作明确决策**：MED 服务质量/连续性、ISR 四项、LON 四项及 OPT 法律/资产/网络连续性，必须取得统一定义下的相应证据，或明确采用有来源、宽不确定性的研究判断。后者是方法选择，不是数据填空；需要同时处理未研究竞争城市，不能只给原 32 城加判断。
4. **最后才讨论总分**：只有测量与研究判断各自归属清楚、居民画像明确、尺度与观察期可比较、标准化锚点另经说明后，才能使用原权重合成。对未覆盖子支柱仍允许全范围取值时，若候选间可能名次重叠，就不能宣称排除了全球其他城市；应先补足足以改变前 32 边界的证据。不得通过给缺失项统一中点来“稳定”排名。

真全球 Top32 的实质阻塞不是文件行数不足，而是 **21 个子支柱当前没有城市测量、10 个只有局部代理、UC 与 eFUA 空间不等价、关键字段自身存在语义冲突，以及部分可及性必须依赖居民身份**。如果选择保留全部原定义，这些都需要证据或明确研究假设来解决；仅把 9,031 个候选跑一遍非空字段排序不能解决。
