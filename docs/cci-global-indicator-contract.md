# CCI 全球指标语义契约：八维、31 个子支柱

审查日期：2026-10-10（Asia/Shanghai）。依据 `src/cci/model.ts` 的实际注册表、[全球资料覆盖研究](cci-global-data-coverage-research.md)，以及本地 UCDB v1.2 手册和提取字典。这里只确定字段可以回答什么，不设评分锚点，不修改发布，不把字段非空率称为 CCI 概念覆盖率。

权重保持 **PCS 15、GSS 15、ISR 15、RES 10、MED 15、LON 10、TEC 10、OPT 10**，合计 100。31 个子支柱均保留。缺测不能记零、均值填补或由其他维度代替；也不能把已测部分重新归一化成完整 CCI 总分。各类资料不是独立证据时不得重复计权。

## 状态与空间边界

- **局部代理**：核验的字段确实测量该子支柱的一部分，但不能宣布整个子支柱已测量，也尚未承诺所有候选都有合格值。
- **未测量**：当前已核验资料没有足以操作化该子支柱的城市测量。可以保留背景证据，但不计作该子支柱的观测覆盖。
- **完整测量**：本轮没有任何子支柱达到这个状态。

以下 UCDB 字段均以**城市中心 Urban Centre（UC）**为统计空间；它们不是 eFUA 的完整观测。`XXXX` 是字典时间占位符，不是承诺每个年份存在。把多个 UC 连接到一个 eFUA 后，仍缺 eFUA 中的其他人口及设施。原字段的区域平均、空间求和与设施计数也不能一律按 UC 人口平均。应保留 `sourceGeography`、`targetGeography`、`spatialCoverage`、观察期、计算方法、来源偏差和许可状态；这些是结果解释所需的记录字段，不要求新增一个框架。

## 字典与方法的即时隔离事项

本轮手册核查发现以下冲突；它们应在主任务的数值审查中形成显式异常记录，而非猜测修正：

1. `EX_010_SHP_XXXX` 的 `name` 写 100 年、`description` 写 10 年；`EX_100_SHP_XXXX` 反之。先不使用两者参与评分。可用相同 epoch 的人口暴露计数与 UC 总人口验算份额，随后与发布方原始模式/更正说明确认重现期；验算相符本身仍不是发布方语义确认。
2. `HZ_CON_FAT_XXXX` 的名称/单位写死亡人数，说明写 one-sided violence 事件，方法又写 point-based 数据的 zonal count。不能默认是死亡求和；核对底层 UCDP 字段及生成方法前隔离。
3. 字典 `SC_CON_DSF_XXXX` 同时对应 fixed 和 mobile 下载速度；不能凭出现顺序选择。核对实际列名、对应表和上游固定/移动层后才能绑定。
4. `CL_UTC_T32_XXXX` 名称是日数，方法提到像元阈值计数/分区平均。可以保留热应激代理语义，但入模前须确认数值单位和上游聚合，不能误作人口热暴露比例。
5. HZ 冲突/灾害字段方法使用含糊的相邻年累计描述，且不同来源年代不同；没有确认窗口前不得作年度发生率或最新安全状况。暴露字段的多个年份有可能只是人口层变化，不代表危险层随年份更新。
6. `SC_SEC_*` 多个变量由同一 Subnational HDI 区域叠加获得；UC 间相同值可能是共享上游空间单元，不应通过去重删除城市，也不应算作多份独立本地证据。HDI、寿命、教育和收入重复使用还会形成内容重复计权。

## 最小可行的下一步与完成条件

### 地震人口分档追加核查（2026-10-10）

`EX_SHA_POP_2025` 的单位是百分比，不是人口数；含义是 UC 内 MMI≥6 分类人口占 UC 总人口的比例。冻结数据的 11,422 行均非空且在 0–100 内，其中 6,849 行为零。进一步用 `EX_E01/E02/E04/E05/E06/E07/E08/E09/E10_POP_2025` 的九组人口复算，高烈度分子与发布比例在 0.01 个百分点容差内全部一致，但所有分档之和与总人口并不总是一致。

以 `max(0.01 人, 总人口 × 0.00001)` 为算术核对容差，73 个 UC 的人口分档之和不等于总人口；其中 8 个有正总人口而九档全部为零：Mindelo（38）、Le Port（157）、Port Louis（159）、Malé（165）、João Teves（219）、Le Tampon（327）、Saint-Denis（481）、Saint-André（623）。它们的发布高烈度占比同样为零，说明“比例可复算”仍不能证明危险覆盖完整。审计输出保存全部异常 ID，源值不改；容差仅用于发现账目差异，不代表模型精度，73 项异常的具体原因尚未确认。

上述 8 项暂不用于零危险或高安全判断；其他零值也仍需结合原始危险层覆盖解释，不因这次核查一律改为缺失。部分人口未进入烈度分类时，不能把该部分默认分到低烈度；也不能把 UC 百分比按面积直接分摊到 eFUA。

[GEM 2023.1 原始发布](https://zenodo.org/records/8409647)说明源危险图是参考岩石条件下、50 年内超越概率 10% 的峰值地面加速度，而非某年的实际震害。UCDB 将其转成 MMI 人口分类所用转换和空间处理仍需核验；人口历元 2025 也不表示危险模型更新到 2025。建筑抗震性、局地土壤放大和实际损失均不能从人口暴露比例直接推得。当前 GEM 产品页另有新版与许可说明，不能据此改变已冻结的 2023.1 上游版本。本轮未下载或重算 GEM 原始危险图，没有生成 PCS 分数。

### 原始地震危险图已取得（2026-10-10）

已从 [GEM 的 Zenodo 2023.1 记录](https://zenodo.org/records/8409647)下载原始 ZIP，共 34,645,808 字节；发布方 MD5、ZIP CRC 和单一 TIFF 检查通过。固定版本为 `v2023.1.0`；API、包内 README 及 LICENSE 均标为 CC BY-NC-SA 4.0，不沿用 UCDB 的整包许可替换上游许可。原包及原图留在临时研究目录，仓库只存[来源与成员校验和](data/cci-seismic-source.json)、[全图扫描结果](data/cci-seismic-raster-audit.json)和复算代码。

原图 `v2023_1_pga_475_rock_3min.tif` 为 EPSG:4326、7,200 × 3,000、Float64。实际横向步长 0.05 度，纵向约 0.0499966667 度，北界 89.99 度；不能按文件名自行构造仿射变换。TIFF 的单位元数据为空，PGA 单位由 README 确认为重力加速度的倍数 g。

21,600,000 个像元中，GDAL 掩膜标记缺失数为 0，但 **15,589,229 个未遮罩值为非有限数**；6,010,771 个值有限且非负，其中 1,405,719 个为零，最大值约 1.893006 g。后续有效性必须同时检查掩膜、有限值和非负条件，不能只看 NoData 标签。有效数值的存在仍不保证该处模型充分覆盖；零值保留但不能直接当成绝对安全。

### 样本条件均值与边界敏感性

`cci_ookla_measurements.py` 在同一冻结季度上读取原始 WKT 多边形，以其地理坐标中心转换到 FUA 坐标系后归属；对照来源提供的取整中心。每个连接类型、每个候选保留一行，不以有无样本筛选候选。各季度文件核验 SHA-256、行数、quadkey 唯一性及瓦片几何。

对下载（kbps）、上传（kbps）、普通延迟（ms），按 `Σ(瓦片均值 × 测试次数) / Σ测试次数` 计算**已选样本条件均值**。每项分别保存有效测试数、有效瓦片数、隔离瓦片数；没有有效测试时均值留空。只纳入正且有限的性能数值，以及正整数的测试／设备数且设备数不超过测试数。零值保留为待解释的隔离记录，既不当断网，也不当零延迟。该处理不把设备总数作为独立用户数，不以瓦片或人口等权替代测试权重。原始均值已取整，结果不具有额外测量精度。

本批全量结果共 18,062 行（9,031 候选 × 两种连接），没有裁掉缺测城市。固定／移动分别有 7,918／8,039 个候选具备中心归属样本下载均值；排除跨边界瓦片后为 7,861／7,977 个。与取整中心相比，原始几何中心改变了 623／348 个瓦片的归属。固定网络中心归属瓦片为 2,921,341，其中 87,965 个未通过完整包含检查；移动为 1,665,247，其中 47,807 个未通过。已归属样本的下载／上传没有被数值规则隔离的瓦片；延迟分别隔离 125／45 个。

两情景均有下载均值的候选中，固定 769 个、移动 1,083 个的均值相对变化超过 5%。这只是诊断阈值，不是合格标准，也不代表其真实网速误差大于 5%；它说明边界处理不能省略。隔离后无数据的候选仍保留空值。

同表另算排除跨边界瓦片后的 interior 情景。它用于观察边界选择对样本均值的影响，**不是统计置信区间或严格上下界**；投影后瓦片边缘用直线段连接，未证明与精确曲线完全一致。中心归属也不表示每次测试都发生在功能区内。`avg_lat_down_ms`、`avg_lat_up_ms` 未参与计算：其部分测试缺测，不能直接以瓦片总测试次数充当分母。

复算命令与落点审计相同，脚本改为 `scripts/cci_ookla_measurements.py`。输出为 [样本测量表](data/cci-ookla-efua-sampled-measurements.csv)和[方法、来源与输出哈希](data/cci-ookla-efua-sampled-measurements.json)。该表尚未接入统一矩阵或页面，不构成完整 TEC 判断；自选样本、地域发布限制、资费、未联网居民和断网时长等问题仍在。

**下一件能完整交付的工作是“全球候选 × 已核验局部代理”的测量底表，而非 CCI 总榜。** 对主任务已经冻结的候选总体，逐字段保存原始值、原始 UC/来源地区、epoch、单位、上游来源与处理状态；保持 `measured / missing / not_applicable / ambiguous` 可区分。任何空间映射失败、来源窗口不明或上面冲突字段均不进入派生指标。此底表允许比较某一明确测量，不能自行改名为完整八维覆盖。

具体依赖按顺序是：

1. **先关闭字段冲突与空间问题**：落实重现期、死亡字段、fixed/mobile、热日数和事件窗口；明确 eFUA 的 UC 人口覆盖、边界跨期一致性及不可比城市清单。数值完整性报告与本语义契约分开保存，避免一个通过掩盖另一个失败。
2. **补能批量取得的实质缺口**：知识产出使用同版 OpenAlex/WIPO 作机构归属与合作分摊；组织暴力使用确认窗口/口径的原始事件；交通冗余需要真实路网和独立替代路径，不能只有长度。先验证字段能覆盖全候选，再决定是否使用；这几项补完仍不足以覆盖其他子支柱。
3. **对当前无法批量测量的概念作明确决策**：MED 服务质量/连续性、ISR 四项、LON 四项及 OPT 法律/资产/网络连续性，必须取得统一定义下的相应证据，或明确采用有来源、宽不确定性的研究判断。后者是方法选择，不是数据填空；需要同时处理未研究竞争城市，不能只给原 32 城加判断。
4. **最后才讨论总分**：只有测量与研究判断各自归属清楚、居民画像明确、尺度与观察期可比较、标准化锚点另经说明后，才能使用原权重合成。对未覆盖子支柱仍允许全范围取值时，若候选间可能名次重叠，就不能宣称排除了全球其他城市；应先补足足以改变前 32 边界的证据。不得通过给缺失项统一中点来“稳定”排名。

真全球 Top32 的实质阻塞不是文件行数不足，而是 **21 个子支柱当前没有城市测量、10 个只有局部代理、UC 与 eFUA 空间不等价、关键字段自身存在语义冲突，以及部分可及性必须依赖居民身份**。如果选择保留全部原定义，这些都需要证据或明确研究假设来解决；仅把 9,031 个候选跑一遍非空字段排序不能解决。
