# LON 干预级证据：注册记录与结果不能混为一项

核验日期：2026-10-10。本次实取两项 ClinicalTrials.gov API v2 记录，并对照 PEARL 正式论文，检验既有 LON 判读规则。两项是方法判例，不是全球干预清单，不能给相关城市优先入围资格。全候选 LON 状态仍为 `not_assembled`。

## 城市归属的实际反例

CALERIE 注册列出 Baton Rouge、Boston、St Louis 三个站点。PEARL 注册列出的设施城市是 Chicago，而论文作者机构地址为 Ann Arbor，研究被描述为分散式设计。上述字段回答的是不同问题，不能任选一个地址作为全部研究活动或居民收益发生地。

因此，进入 FUA 空间匹配前必须保留设施／申办者／作者机构／受试者所在地的角色。注册坐标的精度也尚未在本次核实。两条记录均未分配 FUA，更没有据此增加城市证据覆盖数。即使实际试验站点得到确认，也只证明对应时期的研究活动；已完成试验不能当作目前正在招募的服务。

## 对全候选比较的可执行约束

沿用既有四个子支柱，不新增“试验数量分”：

1. **转化活动**：以去重研究 ID 关联具体机构及角色；多站点研究保留共同研究身份，不能误报成多项独立疗效证明。
2. **试验成熟度**：分别记录注册状态、结果模块、结果论文、主要／次要终点、分析人群与时间；分期不是疗效等级，“已完成”不是成功。
3. **监管采用**：按干预、适应证和辖区核验；研究许可、上市许可与超说明书使用分别记录，现有两例尚未完成这一层。
4. **居民可及**：按已选的当地居民／跨国迁居者口径查资格、供给、费用及当前可获得性；不能从地址或论文推定。

这次核验说明 API 可以取得可追溯研究记录，但不足以直接批量生成城市 LON 分。下一步需要先定义干预纳入范围、跨注册平台去重和全球覆盖检验，再采集符合范围的研究；不能只搜索城市名或使用这两个美国判例形成候选池。入围规则及全候选分母保持不变。
