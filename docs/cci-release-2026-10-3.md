# CCI-2026.10.3：扩展至 32 城研究样本

研究截止：2026-10-10（Asia/Shanghai）。模型保持 2.0.0，数据版本 2026.10.3。

## 本期变化

保留原有 16 城，新增上海、杭州、北京、香港、台北都会区、孟买、班加罗尔、巴黎、柏林、斯德哥尔摩、纽约、墨西哥城、圣地亚哥、内罗毕、开罗、悉尼。每城八维研究判断，合计 256 项，其中本期新增 128 项。

这是目的性研究样本。32 是研究覆盖量，不是全球前 32 名，也不具有概率抽样意义上的全球代表性。地域配额、逐城研究角色及仍然缺失的案例见[32 城选样说明](./cci-sample-32.md)。页面公开覆盖数、已完成八维判断的城市数及选样说明入口。

冻结边界仍为 GHS-FUA R2019A V1.0，年代仍为 2015。新增 16 城的原始 ZIP 校验和、GeoPackage 一致性、精确 ID、源名称、国家／地区代码及城市中心集合已核对；没有复用原样本的 eFUA ID。详见[新增边界属性记录](../src/cci/data/boundary-audit-2026-10-expansion.json)。这不等于验证当前通勤行为，也不等于完成行政统计、设施或服务区到功能城市区的适配；新增城市的观测边界审核保留 `unresolved`。

台北采用 `New Taipei [Taipei]` 的冻结功能区，不能只用台北行政市代表。WIPO 的上海—苏州、台北—新竹及深圳—香港—广州创新集群是不同空间尺度，不能将集群总量重复计入多个城市。原有深圳和旧金山湾区的别名限制继续保留。

审查完成说明已检索、阅读并形成可追溯判断，不等于所有维度都有合格城市实测。国家背景、机构能力和政策计划仍按其真实证据类型展示。没有把计划当成已实现成果，没有生成未经测量的原始指标，也没有提高旧统计审查的 D 等级或观测覆盖率。

新增 128 项审查包含 18 项可保留原始观测、105 项背景证据、5 项证据不足，引用 96 个不同的一手来源 URL。可保留观测也未必覆盖完整功能区。部分材料只能读取来源方的搜索正文片段或目录元数据；各组记录明确列出这类限制，不声称已通读无法下载的附件。因此新增分数主要是有来源支持的结构性判断，不能作为已经验证的城市实测排名。

## 共同尺度与历史可比性

继续使用[模型 2 的固定锚点及权重](./cci-research-model-v2.md)：参考值按 5 分档表达，20/40/60/80 对应从严重脆弱到强能力与冗余的共同尺度。每项披露双语理由、一手来源、8–20 分判断半宽及每十年的主观方向假设。资料薄弱通过明确缺口和更宽区间表达；分数高低须由有依据的结构性判断支持。

新增城市分别与现有亚洲、欧洲、美洲、非洲及大洋洲案例比较评分理由，医疗服务与长寿转化分开；科研生态、注册研究和机构数量均不自动等于居民已经获得有效延寿治疗。评分属于模型辅助研究判断，不是来源机构发布的分数，也不是经概率校准的预测。

原有 16 城的参考值、理由、事件贡献、五个年份的全部结果保持不变。新发布的基线参考日期为 2026-10-10，旧判断按原值结转；它不表示旧证据全部于当天重新观测。模型按基线年份计算时间，因此同年日期调整不改变结果。旧城在扩展名单中的名次变化可以仅由新城市加入造成，不应表述为城市表现恶化。

旧发布 JSON 保持不可变；本期使用新的 `CCI-2026.10.3` 快照及校验和，不覆盖 CCI-2026.10.2。

## 活跃事件的扩展审查

- **欧洲夏季高温**：将同一事件的 PCS −2 判断扩展至巴黎，按 15% 权重贡献总分 −0.3。[Copernicus 八月及夏季分析](https://climate.copernicus.eu/surface-air-temperature-august-2026)明确指出法国显著偏暖；区域信号支持方向，幅度沿用已有研究假设，不声称测得巴黎损失。巴黎结构参考值不重复计入这次事件。
- **柏林与斯德哥尔摩**：没有按“欧洲城市”自动施加同一 −2。来源对中欧的概括不足以认证柏林同幅影响；北欧部分地区表现不同。未加分或扣分仅表示本次没有设置独立事件调整，不表示气候没有影响。
- **ER-100**：保留波士顿申办方生态的 LON +1，未因纽约或其他城市存在生物医药机构而自动扩散。不能从早期试验外推普遍延寿或居民可及。
- 其他新增城市未新增独立事件项。此次不是逐日新闻的穷尽审查；地方长期风险及已有能力在各自结构判断中表达。

所有事件从结构参考值重新计算一次，不将上一版已经调整的分数作为新起点。
