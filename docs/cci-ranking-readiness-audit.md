# 全球 Top 32 可识别性审核

日期：2026-10-10。依据本次审核冻结的全候选覆盖矩阵、`src/cci/model.ts` 的八维权重及 `src/cci/judgment.ts` 的加权计算。结论是**当前协议还不能确定全球前 32**；这不是所有城市相同、数据永远不可得或研究没有价值的结论。

## 当前能够证明什么

[机器核验记录](data/cci-ranking-readiness-audit.json)冻结矩阵和模型哈希。已检查矩阵 CSV 哈希、各维状态数均覆盖 9,031 个候选、全部候选仍为未计算完整全球分、权重之和为 100%。该快照中的 LON、TEC、OPT 在全体候选上均为 `not_assembled`，合计权重 30%。近期临床发现集尚未形成城市维度评估，故不改变这一状态。

覆盖状态本身不能作为分数约束。例如，医疗旅行时间短不自动给 MED 设置 60 分下界；没有归属冲突事件不自动给 GSS 设置高分下界；国家治理背景也没有经过验证的城市分数映射。当前未建立可排除某个候选的总分界限，也未建立任何必然入围证明。这是对现有研究协议的审核判断，不是从 CSV 缺值自动推出城市能力的数学定理。

## 30% 缺口意味着什么

现行模型按八维权重线性聚合。作为**条件性说明**，若前五维均已确定，令其对总分的贡献为 P；如果后三维仍没有比合法量表 0—100 更窄的依据，则后三维贡献的形式范围为 0—30，总分为 P 至 P + 30。

因此，对两城 A、B，仅凭前五维要保证 A 严格高于 B，需要 P_A > P_B + 30。相等只能保证不低于，不能保证严格领先；简单 ID 排序不能把并列变成实质优劣。这个示例没有把任何现实城市赋值为 0 或 100，也不声称它们都能实际达到端点。现实前五维并未全部确定，不能将上述条件性范围误作本轮城市置信区间。

一般地，只有在每城上下界有可辩护依据时，才可作保守判定：

- 至少 32 个其他候选的下界严格大于某城上界，才足以证明该城不在前 32。
- 最多 31 个其他候选的上界大于或等于某城下界，才足以在并列不利处理下保证该城入围。

这些是充分条件，不是概率估计。各维或城市间的联合约束可能使界限更紧，但必须有依据；研究展示半宽不满足这一用途。仅在资料较多城市之间算敏感性，不会处理其余候选的入围可能性。另有 1,861 个新城市中心未与旧候选边界相交，旧库内部排名即使稳定，也不能单独证明全球覆盖成立。

## 据此调整下一步工作

继续扩充临床试验命中数不会直接缩小城市总分范围。下一阶段应优先完成可执行的维度判断实例：用既有医疗旅行时间作为一层证据，再核验当地居民的实际医疗资格、常规／专科质量与连续性，明确支持档位及尚不能确定的部分。试点用于校准规则，不是预选入围名单；规则须能应用到全部候选，资料缺失保留待定。

在形成至少一套完整维度判断并验证判读一致性前，不将局部代理映射为分数，也不新增一个手选的 32 城发布。跨国迁居者画像仍待用户指定；它影响身份相关部分，但不阻止当地居民口径和共同证据工作。

本轮未改权重、历史发布或线上研究样本；审核不是目标完成。它把下一步从继续累积单类资料，转向检查证据是否真的能够支持同尺度城市判断。

后续已按候选来源 ID 从赫拉特开展[MED 四子支柱判读实例](cci-med-herat-review.md)。模型通达较近与现实费用、群体通行及服务压力可以同时成立；本实例仍缺完整质量、专科和连续性依据，未赋分或排除候选。

后续更新：统一矩阵已接入 2026 Q3 网络样本，TEC 不再全部为 `not_assembled`，其中 8,255 个候选有局部样本、776 个缺样本。上述机器记录保留其原始哈希，属于接入前快照。局部测量尚未建立 TEC 分数或合法量表之外更窄的可辩护界限，因此不据此把条件性 30 分示例缩为 20 分；全球完整评分及入围证明仍未建立。
