| GSS      | 993 个候选有归属明确的历史事件；8,038 个未归属到事件                                | 未归属到事件不等于安全或零风险；历史事件不覆盖区域冲突外溢与战略暴露                               |

| RES      | 8,595 个候选可引用至少一项国家城市人口饮用水背景，436 个缺失                        | 国家城市人口比例不等于该功能区供水可靠性，也不覆盖食物、能源或供应链                               |

| LON      | 9,031 个候选尚未组装合格的同口径测量                                                | 试验与研究活动不自动证明临床收益或居民可及                                                         |
| TEC      | 8,255 个候选有 Q3 2026 局部网络样本；776 个缺样本                                   | 自选测速不代表居民覆盖、知识产出、产业或技术扩散                                                   |

“尚未组装”不等于没有任何相关资料，也不是城市表现差；它表示该证据还没有在这一统一候选口径下形成可用测量。已关联证据仅支持 `geophysical` 的部分危险模型、`organized_violence` 的部分历史、`governance` 的国家背景、`water` 的国家城市人口背景、`access` 的部分历史模型与 `digital_infrastructure` 的部分自选测速样本；另为 `transport_redundancy` 保存机场目录点，不是已测量冗余。不能将这些关联解释为完整维度，也不能按已关联维度数量报告完成率。地震计算及其缺失处理见[全候选汇总](cci-seismic-population.md)，饮用水指标的包含关系及尺度限制见[饮用水背景](cci-water-context.md)。

## 输出与复算

- [全候选八维矩阵](data/cci-global-evidence-matrix.csv)：每个 eFUA 一行，保留八维状态、历史研究范围、UCDB 与 WUP 2025 各自的交集信息、归属事件数、WGI 背景关联数量及未计算总分状态。
- [汇总与溯源](data/cci-global-evidence-matrix.json)：各维状态分布、输入数据及其来源清单哈希、实现和输出哈希。
- 来源原值仍分别保存在 UCDP、医疗人口加权、WGI 与空间审查表中，均可按 `efua_id` 追溯。矩阵不复制国家分数进城市，不将旧的联合功能区研究分配给每个组成区域。

```sh
pnpm exec python3 -B scripts/cci_global_evidence_matrix.py
pnpm exec /private/tmp/cci-global/geo-venv/bin/python -B -m unittest discover -s scripts -p 'test_cci_*.py'
```

合并前检查每份输入与既有清单的哈希，且每表的候选 ID 集合必须与全集完全相同。缺行、增行或重复 ID 直接报错；不做丢失候选的内连接。78 项离线研究测试通过，相关检查包含全集保留、重复拒绝、零归属事件不变为零风险、国家背景不变为城市得分、旧联合研究不变为成员分数，以及机场目录数量与无点状态不变为交通能力分数。

## 对全球 Top 32 的影响

目前 **9,031 个候选都没有在全球统一评分协议下计算完整 CCI**。这是现有实现状态，不是给它们同分或断言永远无法评分。UCDB 的较新中心与旧功能区仍存在覆盖差异，数据时点也不统一；尚无可用于全球总榜的完整指标映射及锚点。

已按[评分校准](cci-local-2026-scoring-calibration.md)把统一判读规则用于本矩阵的提前排除审查；这只检查已组装证据能否支持停止深入调查，**不是全量城市的八维评价已经完成**。原局部状态不变，新增当地居民案例状态、审阅文件、保留状态与理由，并记录案例及其证据文档的哈希。

| 审查结果                 | 数量  | 含义                                                                   |
| ------------------------ | ----- | ---------------------------------------------------------------------- |
| 有条件性八维校准案例     | 3     | 新加坡、伦敦及赫尔辛基；来源、反证与假设已逐项审阅，不自动授予入围资格 |
| 尚无此类八维评价         | 9,028 | 不填中点、不记零、不因资料量少排除                                     |
| 现有证据可支持的提前排除 | 0     | 局部代理不能限定完整维度；条件性分数及研究半宽也不是可靠排除界限       |
| 继续保留为可能竞争者     | 9,031 | 未建立合格的第 32 名门槛；三城条件性总分不能作为该门槛                 |

地震、冲突历史、国家治理与饮用水背景、医疗旅行模型、测速和机场目录分别只有表中已说明的证明范围；逐行关联再多种局部资料也不能推出整个维度最高只能得多少。因而这轮审查没有形成任何适用的排除界限，不给未审城市设置低上限。较新未匹配中心亦继续属于全球目标待处理范围，未混入本次旧功能区计数。

下一步须将同样的支持／反证／假设要求推进到更多候选的实际八维判断，优先解决会改变入围结论的未知项；不能用再增加代理来源代替评分。总榜之前仍须检查所有可能影响第 32 名的候选，不能让资料丰富或旧有研究名额成为入围条件。

本轮没有改变八维权重、历史发布或生产城市评分。独立研究进展页面展示覆盖数量及限制，完整目标仍未达到发布条件。
