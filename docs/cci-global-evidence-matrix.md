“尚未组装”不等于没有任何相关资料，也不是城市表现差；它表示该证据还没有在这一统一候选口径下形成可用测量。已关联证据仅支持 `geophysical` 的部分危险模型、`organized_violence` 的部分历史、`governance` 的国家背景、`water` 的国家城市人口背景、`access` 的部分历史模型与 `digital_infrastructure` 的部分自选测速样本，不能解释为六维已完成，更不能按 6/8 报告完整度。地震计算及其缺失处理见[全候选汇总](cci-seismic-population.md)，饮用水指标的包含关系及尺度限制见[饮用水背景](cci-water-context.md)。

## 输出与复算

- [全候选八维矩阵](data/cci-global-evidence-matrix.csv)：每个 eFUA 一行，保留八维状态、历史研究范围、UCDB 交集信息、归属事件数、WGI 背景关联数量及未计算总分状态。
- [汇总与溯源](data/cci-global-evidence-matrix.json)：各维状态分布、输入数据及其来源清单哈希、实现和输出哈希。
- 来源原值仍分别保存在 UCDP、医疗人口加权、WGI 与空间审查表中，均可按 `efua_id` 追溯。矩阵不复制国家分数进城市，不将旧的联合功能区研究分配给每个组成区域。

```sh
pnpm exec python3 -B scripts/cci_global_evidence_matrix.py
pnpm exec /private/tmp/cci-global/geo-venv/bin/python -B -m unittest discover -s scripts -p 'test_cci_*.py'
```

合并前检查每份输入与既有清单的哈希，且每表的候选 ID 集合必须与全集完全相同。缺行、增行或重复 ID 直接报错；不做丢失候选的内连接。45 项离线研究测试通过，新增检查包含全集保留、重复拒绝、零归属事件不变为零风险、国家背景不变为城市得分和旧联合研究不变为成员分数。

## 对全球 Top 32 的影响

目前 **9,031 个候选都没有在全球统一评分协议下计算完整 CCI**。这是现有实现状态，不是给它们同分或断言永远无法评分。UCDB 的较新中心与旧功能区仍存在覆盖差异，数据时点也不统一；尚无可用于全球总榜的完整指标映射及锚点。

下一步应优先把已取得的 PCS/RES/TEC/OPT 局部字段推进为语义、边界和年份明确的候选测量，并补 LON 的干预级证据链；同时建立研究判断与测量如何结合的统一规则。继续增加来源数量本身不会解决概念缺口。总榜之前仍须检查所有可能影响第 32 名的候选，不能让资料丰富或旧有研究名额成为入围条件。

本轮没有改变八维权重、历史发布、城市评分或线上页面。完整目标仍未达到发布条件。
