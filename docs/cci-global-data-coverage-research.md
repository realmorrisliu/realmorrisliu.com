# CCI 全球选样的数据覆盖审查

审查日期：2026-10-10（Asia/Shanghai）。只研究数据可用性，不生成评分、名单或修改发布。范围是 `src/cci/model.ts` 中 MED、LON、TEC、OPT 的 16 个子维度，合计占 CCI 权重 45%。

**结论：目前核验的全球资料足以建立候选城市的部分共同底表，不能直接产出可信的“全球 CCI 前 32”。** 数据规模大、具有坐标或可下载，不等于覆盖全球所有城市，也不等于观察到居民实际能力。现有 32 城研究判断只能比较已选样本，不能证明它们优于未研究城市。本结论是依据以下覆盖缺口的研究推断，不是宣称不存在其他数据。

## LON 不能用“热度”填满

当前代码同时要求研究转化、试验成熟度、监管采纳和居民可及。前三者必须围绕同一干预建立链条，不能把论文数量、某药其他适应证获批、所在地设有诊所拼接为延寿证据。监管机构对未经批准再生产品的[官方警示](https://www.fda.gov/safety/medical-product-safety-information/public-safety-alert-due-marketing-unapproved-stem-cell-and-exosome-products)说明注册、营销和获批并非一回事；美国监管结论也不能外推为全球统一状态。

本次未找到覆盖全球 FUA、同时核查疗效与普通居民可及性的统一 LON 数据集。这应标成未覆盖并拓宽研究不确定性，不能把缺失直接判为城市差，也不能借同国其他城市的研究能力补齐。

## 怎样才能声称“从全球选出 32”

先冻结全球候选总体、FUA 边界和观察日期，再对所有候选运行相同字段、同年窗口及缺失规则。否则对 32 座完成研究仅说明这 32 座被研究过。MED、LON 的居民资格和实际可及，以及 OPT 的法律/资产身份依赖，需要明确居民画像或分画像结果；不宜隐含默认富裕外籍人士或当地公民。

可先对整个总体建立公开、可复算的**部分维度筛查**，随后对可能影响前 32 边界的城市补证并做缺失、权重和模型敏感性审查。结果应区分“按已声明代理指标和覆盖条件得到的候选前 32”与“全球最优的客观前 32”。现有资料不能支持后者；加入研究者判断可以形成有条件的研究排名，但必须公布判断占比与未研究竞争城市的不确定性。

本次未下载全量数据、未实跑全球覆盖率、未对付费产品报价/授权，也未完成逐城医疗与监管核验。表中“未核验许可”不等于禁止使用，只是不宣称已获批量再发布权。
