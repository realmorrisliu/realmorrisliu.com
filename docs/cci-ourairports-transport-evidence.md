# OPT 机场目录：全量落点与服务标记核查

核验日期：2026-10-10。为 OPT 的 `transport_redundancy` 补充交通设施底表，不生成交通冗余、居民可及性或 OPT 分数。

## 来源与冻结

[OurAirports 下载说明](https://ourairports.com/data/)将目录置于公有领域，同时不保证准确性或适用性。采用其官方仓库的 [2026-10-10 提交](https://github.com/davidmegginson/ourairports-data/commit/056cc323e5704413e08ee75586341378013ac6c8)，不使用会继续变化的默认分支 URL。CSV 的 12,743,789 字节及 Git blob SHA-1 与官方内容 API 一致，另保存 SHA-256。完整来源、冻结下载链接和限制见[来源清单](data/cci-ourairports-source.json)。提交和采集日期不代表各条设施记录的独立观察日期。

[字段说明](https://ourairports.com/help/data-dictionary.html)将 `scheduled_service=yes` 定义为当前提供定期航空服务，但目录没有航班完成、运力、票价、转乘或居民资格字段。`municipality` 是所服务城市，未必是机场所在城市，因此只按坐标匹配。字段说明列出 `closed_airport`，本次实际 CSV 使用 `closed`；两种关闭类型均可识别，实际原值保留。

## 实际全量结果

- 86,231 条记录，内部 ID 与 `ident` 各自唯一；全部记录保留。所有坐标都可解析且在经纬度合法范围内，不代表坐标已独立核实。
- 类型包括 42,803 个小机场、23,238 个直升机场、13,574 个关闭机场、4,105 个中型机场、1,175 个大型机场、1,273 个水上基地及 63 个气球港，不能将全部记录称为可用客运机场。
- 23,760 个目录点唯一落在冻结 eFUA 内，62,471 个在框架外；没有坐标缺失、非法坐标或多功能区匹配。这是当前目录与旧边界的连接结果，不证明当前全球城市覆盖完整。
- 9,031 个候选全部保留；3,094 个有目录点，5,937 个无区内点。其中 1,338 个候选有标记为定期服务且非关闭状态的点，共 1,479 个。
- 4,335 条记录标记定期服务，其中 8 条同时标记关闭。矛盾记录保留并列出标记，排除在“定期且非关闭”计数之外，不擅自判断其中哪一个字段正确。剩余 4,327 条中，2,848 个在冻结功能区外，1,479 个在区内；因此仅统计区内点会遗漏大量可能服务居民的机场。

[逐机场空间连接](data/cci-ourairports-fua.csv)、[全候选目录覆盖](data/cci-ourairports-efua-coverage.csv)和[对账及输出哈希](data/cci-ourairports-fua-audit.json)可复算。完整记录不是目录完整性的证明，未登记也不证明不存在设施。

## 判读与下一步

机场存在或 `scheduled_service=yes` 不证明居民能负担、获得资格、及时到达并乘机；两个点不证明独立替代通道。关闭、军事或私人设施以及海陆交通需要按实际条件查证。区外机场可能是主要服务设施，不把“区内无点”转为无航空通道或低分，也不凭最近距离默认跨境通道合法可用。

后续要核对居民到机场的真实接驳与资格、实际航班目的地／频次／完成情况、票价与容量、地面及跨境替代路线，并检查共用空域、天气、能源、接驳和边境关闭造成的共同失效。当地居民与迁居者可共享设施底表，但身份、预算和合法通道分别判断。法律迁移、资产可携及网络连续性仍未形成完整评估。

本次将目录点与定期服务标记接入全候选矩阵，OPT 状态仅表示设施目录关联；没有提升为完整维度或全球排名资格，也没有改变八维权重和历史发布。
