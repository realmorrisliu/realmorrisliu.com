## 2026年住院保障：先确认参保、日期与医疗机构级别

以下是S1第5—7条的**普通在职职工/居民**待遇，不含日间手术、严重精神障碍特殊起付规定或退休职工增加上限。支付比例只作用于起付标准以上的政策范围内费用，并受年度累计上限限制。

| 佛山市内定点医疗机构级别 | 职工每次起付 / 基金支付比例 | 居民每次起付 / 基金支付比例 |
| ------------------------ | --------------------------- | --------------------------- |
| 一级及以下               | 250元 / 93%                 | 300元 / 90%                 |
| 二级                     | 500元 / 90%                 | 600元 / 85%                 |
| 三级                     | 1000元 / 87%                | 1200元 / 80%                |

市内符合临床转院标准的转院，转入机构起付较高才收取差额，较低或相等不再计算；这条是**市内**规则，不能未经核实套给佛山转广州。新办法实施前后跨日期出入院，第40条规定直接结算按入院日计算起付与支付比例，零星报销按入院日核定待遇。故上表不能追溯套给2026年1—4月入院，也不能只因出院在5月以后就套新表；本次未另审旧办法。

职工年度基金最高支付限额按连续缴费时间分为上上年度本市城镇单位在岗职工年平均工资的1倍（不足3个月）、4倍（满3个月不足12个月）、6倍（满12个月）；居民为上上年度城乡居民人均可支配收入7倍。第39条说明是自然年度内住院、家庭病床、门特、居民生育等基金支付累计额，不能误作每次住院上限。这些是**法定计算基准，既不是画像中位收入也不是本次核实的2026具体金额**；没有用缴费通知代替待遇额度。

## 等待期、断缴与谁承担空档费用

S3/S4第5—6条区分资格：佛山市用人单位职工应参保，本市就业的灵活就业者可以参保；居民医保主要覆盖未参加职工医保的佛山户籍人员，并另列非本市户籍在校学生、符合父母缴费条件的婴幼儿、持本市居住证的未就业港澳台居民等资格。**通常长期居住与中国公民身份本身，不能据此证明普通非本地户籍成年非就业者可参加佛山居民医保**；目标居民实际户籍、就业与现有参保地仍须明确。

- **正常职工**（第13条）：缴费次月起享受，停止缴费次月起停止。用人单位自中断缴费次月起1个月内补缴费用和滞纳金，缴费当月可恢复并追溯空档待遇，补缴时段计连续；超过1个月补缴，重新缴费次月起享受，空档医疗费用由用人单位承担、基金不追溯，连续缴费重新计算。法律责任不等于已经及时向居民偿付的结果。灵活就业中断超过同一期限，空档不予补缴，次月恢复并重新计连续。
- **正常连续居民**（第14条）：通常每年10—12月集中缴下一年费用，次年1月1日起享受；中途加入按全年标准缴，不因只用剩余月份自动按比例减费。本次没有核实2026年度是否另有集中期延长通知，画像“通常保障”只可在已按规定持续参保缴费的推定下使用。
- **居民逾期或断保**（第14条第6项）：自2025年起通常设固定3个月等待；每多断保1年再加1个月变动等待，额外缴费可修复变动部分，连续断缴4年以上修复后合计原则上不少于6个月。新生儿、重点救助及支出型医疗救助对象、符合条件的退役军人和其他优抚对象、重度残疾人、刑满释放人员等第7条情形中途参保不设等待，不能将例外推广给普通成年居民。
- **转移/跨制度衔接是另有规则**（第28—29条）：职工跨市转入中断次月起3个月内可以按规定补缴并追溯，原已连续参保2年以上在职工与居民间切换也有3个月衔接规则；不能以本市普通断缴1个月规则覆盖所有转换，更不能以转换例外消除所有居民固定等待。

## 名义比例之外的自付与现金压力

S1第22条规定目录、医保支付标准和实际价格共同确定核报范围；超支付标准部分不支付。S2在佛山市本地待遇中具体保留：住院乙类药职工/居民先自付均5%；治疗费住院先自付职工5%、居民7%；化验、检查与其他费用住院先自付职工10%、居民15%；一般医用耗材先自付职工25%、居民30%，单件限价通常48000元（人工耳蜗、主动脉支架76000元），并有透析材料等例外；普通床位原则上以二人间收费标准作为支付标准。起付、自付比例、目录外与超标准费用、基金支付后的个人分担，以及超过年度上限部分不能压成一个“87%/80%报销全部账单”的说法。异地的支付范围按国家、省规定执行，不能把佛山本地附件费用目录直接当广州所有医疗项目的同一核报范围。

S1第34条规定市内定点和市外联网机构应直接结算，个人支付个人承担部分；直接结算失败且不能补记账或非联网机构就医，先个人垫付再零星报销。故即便最终有法定报销权，仍有短期全额垫付、补记账或报销时间的不确定现金压力。第37条保留索取真实费用单据及向经办机构咨询的权利，但本次无实际成功率、平均回款时间或争议纠正结果。第38条等还排除应由工伤、公共卫生等承担及境外费用；不符合入院标准或医嘱出院后拒绝出院的后续费用也不由统筹承担。

## 对上层审计的可用结论与未闭连接

已闭合的连接是：官方有效原文 → 2026年5月以后普通住院基础待遇 → 佛山赴广州四类待遇分流 → 参保资格/等待与断缴责任 → 目录内先自付、限价及垫付。**缴费费率本身不证明这些待遇，也不证明居民实际可用**。跨佛山的9711画像可采用“符合佛山职工或居民参保资格且通常连续有效缴费”的可撤回假设，在法定保障层描述以上路径；若采用普通居民医保，还必须明确本地户籍等资格。缺这一连接时不能套广州参保规则，也不能凭长期居住填平。

仍未闭合：具体目标住址所属9711边界和参保地；居民实际就业/户籍资格；具体广州救治机构、转诊与备案能否及时完成、联网直接结算；中位收入下真实疗程目录外、先自付及年度累计负担；断缴责任偿付与零星报销的实际居民触达；2026年1—4月入院旧规则；单独年度支付上限金额及可能的后续调整。本次故保留这些未知，不扩大一般医疗研究、不将条款证据升级为MED整体80或实际无障碍访问。
