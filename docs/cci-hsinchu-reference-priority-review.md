## 制度与医疗：服务已经运行，范围仍有限

[S05血液科](https://www.hch.gov.tw/?aid=60&pid=6)明确有肿瘤诊断／突变信息、定期多专科讨论，疑难病理向台北总院复阅；有化疗／输血、出血感染处理、个管追踪治疗困难或失联，以及每周访视或电话联系的居家安宁。它支持具体服务与知识使用，未给当前全区风险调整结局，不把医院名称、认证或设备配置单独当质量。

限制同读：2016认证／PET启用与2021改制为旧窗口，临床试验人力及化疗室改建仍有未来／计划表述。“即将超过2000”不是已经年治2000的实际数。[S02医师页](https://www.hch.gov.tw/?aid=51&pageNo=1&page_name=list&pid=6)列七位，S05称二专任二兼任；虽同标2026-07-24更新，版本／人群未解，不拼成当前编制，也不把更新时间当正文全部新写的证明。不能从移植专长或挂号入口推断已在491实施HSCT。

[S16整合照护](https://www.hch.gov.tw/?aid=617&pid=0&page_name=detail&iid=101)署2026-09-11，限新竹医院6B病房、有意愿且经评估合条件者，收费新台币1,050／人日。家属自行照护、原聘外籍看护连续照护、ADL满分及需1对1者不纳入；出院或转出该病房即终止。这是具体已实施帮助与真实限制，不是全院、全居民或所有护理费用的上限，也不证明每人实际得到或全部报销。

普通NHI资格仅复用[台北已采用的资格记录](data/cci-local-2026-taipei-case.json)的国籍、户籍、通常长期参保摘要C01，根核其与当前规范记录对象及字节身份一致。本轮没有重获该NHI原文或完整工具正文，不认证现行所有资格细节、项目目录、报销比例或患者账单。原403失败源没有换渠道恢复；资格不同、尚在等待或未有效参保的画像不能直接套用。

根接受MED60的实质判断是：实际本地必要诊疗与会诊／追踪能有限代表日常质量，通常有效保障及中位资源下的必要病程付款、1对1或其他病房的照护安排、交通及接续通常可管理。正证是实际服务与具体辅助，不能由目录或“未见失败”补成。自付、排除与拥挤并未被忽略；若不接受通常付款、质量或净反复照护判断，MED未知，域15—90；没有已核重要帮助后必要护理后果，本批不硬列40，不需多数、崩溃或死亡门槛。

ISR60还接受台风实际清障、问题跟踪与临床个管／已实施照护共同对通常执行能力的有限代表，非仅凭单一咨询入口。市与功能区、服务对象和2024／2026到截止的延续连接可撤；拒绝ISR则域15—90。

## 技术：具体专业产用，不能由正常运营自动给分

S05的链条是技术信息／疑难复阅，形成当地诊断分类和多专科处置判断，再进入本地治疗及个管反馈。根接受这一持续知识密集服务对普通居民可用技术能力的有限代表，TEC60并非只因采购PET、名单含专家或医院在运营。它不要求当地发明每个技术，但也未证原创研发、全部基因／病理实验在491完成，不能把台北复阅全搬成本地生产。跨院知识回流和本地专业判断／执行必须一同解释。

[W02官方园区工具条目](https://explore.sipa.gov.tw/)提供2025营业额17,001.16亿元、员工179,298的多年序列，是多个园区的总量背景，不分配为491的产业产出／居民触达，更不把WIPO名次换分。深圳的数据库治理和已完成交易不移植为新竹事实；Gorzow当前TEC未知但60也可辩，不能将其已有产用贬成只有计划来制造差异。两案差异依明确接受的本地专业产出—使用代表判断，并不证明新竹客观技术更高。

独立TEC窄审支持此有限解释。若只接受成熟诊疗输入，仍不足以接受持续本地产出或通常较广技术能力代表，TEC回未知，域18—88；未见实质产用断裂不填40，不索全民AI或每节点制造复产。三个60全撤为0—100。
